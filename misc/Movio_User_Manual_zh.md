| 项目 | 内容 |

![Movio 主机与 3D 打印外壳](../img/case_and_board_s.png)

*图 1：Movio 主机与卡扣式 3D 打印外壳*

Movio 是一台用一套键盘和鼠标控制两台电脑的硬件 KVM 切换器。它不需要在电脑上安装任何软件：把鼠标指针移到屏幕边缘，光标就会"穿"到另一台电脑，键盘输入也会自动跟随。对于经常在 Windows、macOS、Linux 或 Android 之间切换的用户，Movio 的目标是让两台电脑用起来像一台。

本手册面向 Movio 成品、套件和 DIY 整机用户，覆盖安装连接、首次配置、日常使用、快捷键、Web 配置页、固件升级、状态诊断、故障排查和安全注意事项。不同硬件版本、外壳版本和销售包装可能存在差异，请以您手中的实物和项目最新发布说明为准。

## 使用前必读

> **重要提示**
>
> 1. Movio 只切换**键盘和鼠标**，不切换视频、音频、USB 存储或其他 USB 数据。显示器仍应直接连接各自的电脑。
> 2. 两台电脑都必须通过 USB 为 Movio 提供供电；只连接一台电脑时，设备无法完成双机切换。
> 3. 固件升级过程中不要断开 USB 线或关闭电脑，否则可能导致升级失败。
> 4. Web 配置页使用 WebHID，请使用 Chrome、Chromium 或 Edge；Firefox 和 Safari 不支持。
> 5. 配置页中的修改会立即下发到设备，但只有点击"保存"后才会写入 Flash；未保存的修改在退出或断电后丢失。

### 快速开始

1. 将**键盘**插入带有键盘图标的 USB-A 输入口，将**鼠标**插入带有鼠标图标的 USB-A 输入口。
2. 用两根支持数据传输的 USB 线，把 Movio 的 **A 端**和 **B 端**分别连接到两台电脑。
3. 打开两台电脑，等待几秒钟让设备完成 USB 枚举。
4. 把鼠标移到屏幕边缘并继续移动，光标应穿到另一台电脑；键盘输入也会跟随。
5. 如果方向或高度不正确，按 `左 Ctrl` + `右 Shift` + `C` + `O` 进入配置模式，打开 `config.htm` 调整。
6. 如果两台显示器高度不一致，按 `右 Shift` + `F12` + `Y` 校准切换高度。

## 1. 文档说明与安全须知

### 1.1 适用范围

本手册适用于 Movio v0.80 及当前 main 分支固件。仓库 `VERSION` 当前为 0.80，main 分支还包含 v0.80 之后的改进（例如板载 LED 模式和游戏模式默认开关）。Movio 是 [hrvach/deskhop](https://github.com/hrvach/deskhop) 的衍生项目，硬件由两块 Raspberry Pi Pico、数字隔离器和 USB 接口组成。项目仍在持续更新，以下内容可能随固件版本变化：

- 快捷键组合和配置项名称；
- Web 配置页的布局和中文翻译；
- LED 指示行为；
- 固件升级流程和兼容性说明。

如果本手册与设备实际界面不一致，请以设备读取到的配置项和项目发布说明为准。

> - 外壳、螺丝、线缆等小部件请远离儿童和宠物。

## 2. 产品概述

### 2.1 产品定位

Movio 是一台**纯硬件、免驱动、双机键鼠切换器**。它在键盘、鼠标与两台电脑之间充当中介，同时与两台电脑保持 USB 连接，并根据当前选择把键鼠输入转发到其中一台。

它适合以下场景：

- 一台工作电脑 + 一台个人电脑，共用一套键鼠；
- Windows / macOS / Linux / Android 混合桌面；
- 需要物理隔离、不希望安装软件或联网的办公、研发和设计环境；
- 需要在两台电脑之间快速切换，但不能接受软件 KVM 延迟或兼容性问题的场景。

Movio **不是**视频 KVM、USB 集线器、扩展坞或网络 KVM。显示器、音箱、摄像头、移动硬盘等设备仍应直接连接各自的电脑。

### 2.2 主要功能

| 功能 | 说明 |
|------|------|
| 鼠标穿屏 | 光标移动到屏幕边缘即可切换到另一台电脑，无需按键 |
| 键盘跟随 | 切换输出时键盘自动跟随；也可用快捷键独立切换 |
| 免驱动 | 两台电脑都无需安装软件，使用标准 USB HID 协议 |
| 跨系统 | 支持 Windows、macOS、Linux 和 Android |
| 多显示器 | 每个输出可在配置页选择 1–3 块屏幕，两台合计最多 6 块 |
| 物理隔离 | 两路输出之间通过数字隔离器实现 2kV 设计隔离电压 |
| Web 配置 | 本地 WebHID 配置页，支持中文/英文切换，默认中文 |
| 快捷键 | 游戏模式、慢速鼠标、切换锁定、系统锁定、屏幕保护等 |
| LED 指示 | 板载 LED 可配置为活动输出、短空闲、长空闲、仅状态闪烁或禁用 |
| 双板升级 | 通过 `MOVIO` 虚拟盘升级一块板后，另一块板可自动同步 |
| 开源 | 代码、硬件设计和文档开放，可自行审计和编译 |

### 2.3 工作原理

Movio 的核心是两块 Raspberry Pi Pico（RP2040），每块板对应一台电脑。两块板通过 UART 和数字隔离器通信，键盘、鼠标则连接在 USB-A 输入口上。

```text
   键盘 ──USB──▶ [键盘口] ─┐
                            ├── Movio（Pico A + Pico B + 隔离器）
   鼠标 ──USB──▶ [鼠标口] ─┘
                            ├── A 端 ──USB──▶ 电脑 A
                            └── B 端 ──USB──▶ 电脑 B
```

- **鼠标**：设备把鼠标的相对移动转换成绝对坐标（0–32767），再发送给当前活动的电脑。当光标到达屏幕边缘并继续朝另一台电脑方向移动时，设备保持 Y 坐标不变（或按校准值缩放），把 X 轴翻到另一侧，同时切换活动输出。光标就会在另一台电脑的屏幕上以相近高度出现。
- **键盘**：键盘报告只发送给当前活动输出。通过鼠标切换输出时，键盘自动跟随；也可以通过 `左 Ctrl` + `Caps Lock` 独立切换。切换时设备会释放所有按键，避免按键"卡住"。
- **LED**：设备会分别记录两台电脑的键盘 LED 状态（如 Caps Lock、Num Lock），切换时恢复对应状态。板载 LED 和键盘 LED 也可以用作输出指示。
- **隔离**：两路输出之间通过数字隔离器隔开，避免两台电脑之间形成电气通路；设备不提供任何跨电脑的数据传输通道。

### 2.4 产品边界：能做什么，不能做什么

| 可以做 | 不能做 |
|--------|--------|
| 用一套键鼠控制两台电脑 | 切换显示器、视频信号或音频 |
| 鼠标穿屏、键盘跟随 | 在两台电脑之间拖拽文件、复制粘贴 |
| 保存两台电脑各自的键盘 LED 状态 | 共享剪贴板、麦克风、摄像头或 USB 存储 |
| 多显示器布局和高度校准 | 通过 Wi-Fi、蓝牙或网络远程控制 |
| 游戏模式、慢速鼠标、切换锁定 | 给笔记本充电或作为 USB 充电器 |
| 通过本地网页调整参数 | 绕过操作系统登录、安全策略或 EDR |

> **安全提示**：Movio 不能替代物理隔离网闸或数据二极管。如果两台电脑属于不同安全域，请遵循您所在组织的安全规定，不要仅依赖 Movio 做安全边界。

### 2.5 与 DeskHop 的关系

Movio 基于 [hrvach/deskhop](https://github.com/hrvach/deskhop) 开发，保留其核心切换逻辑，并增加了中文/英文配置界面、界面视觉更新、固件稳定性修复、鼠标切换优化、LED 同步机制和一键构建脚本等改进。详细的差异对比请参阅 [Movio 与 DeskHop 对比](Movio_vs_DeskHop.md)。

## 3. 部件与接口

### 3.1 包装与必备部件

不同销售形式（成品、套件、DIY）包装内容不同。下表列出完整使用 Movio 所需的部件，请按实际包装核对：

| 部件 | 是否必需 | 说明 |
|------|----------|------|
| Movio 主机 | 是 | 已组装成品、套件或 DIY 主板 |
| USB 数据线 ×2 | 是 | 连接两台电脑；标准 Raspberry Pi Pico 使用 Micro-USB，若硬件版本为 USB-C 则使用 USB-C |
| USB 键盘 | 是 | 有线键盘或带 USB 接收器的 2.4GHz 无线键盘 |
| USB 鼠标 | 是 | 有线鼠标或带 USB 接收器的 2.4GHz 无线鼠标 |
| 3D 打印外壳 | 否 | 视销售版本而定，卡扣式，无需螺丝 |
| 快速指南/保修卡 | 否 | 视销售版本而定 |

> 如果包装中缺少必需部件，请联系销售方。DIY 套件请按项目物料清单核对元件，不要遗漏数字隔离器和 USB 连接器。

### 3.2 接口布局

![Movio PCB 与接口](../img/pcb_render_s.png)

*图 3：Movio PCB 的 USB-A 输入口与两块 Pico 的 USB 设备口*

```text
   ┌──────────────────────────────────────────────┐
   │                  Movio 主机                   │
   │                                              │
   │  [键盘 USB-A] ──┐              ┌── [A 端 USB] ──▶ 电脑 A
   │                 │              │              │
   │  [鼠标 USB-A] ──┘              └── [B 端 USB] ──▶ 电脑 B
   └──────────────────────────────────────────────┘
```

- **USB-A 输入口**：两个都是 Host 口，用于连接键盘和鼠标。外壳顶部通常有键盘、鼠标图标。
- **A 端 / B 端**：两个 USB 设备口，分别连接两台电脑。标准 Pico 为 Micro-USB 接口；若您的硬件使用 USB-C 接口，请使用对应的 USB-C 数据线。
- **A/B 丝印**：位于 PCB 或外壳上，用于区分两台电脑。接反不会损坏设备，但需要在配置页把"屏幕位置"对调。
- **不要**把键盘、鼠标插入 A/B 端，也不要把电脑插入 USB-A 输入口。

> **关于线缆的说明**：项目部分早期文档把电脑连接线写作"Type-C"。标准 Raspberry Pi Pico 的 USB 口是 Micro-USB；请以您手中主控板的实际接口为准，使用匹配的**数据线**，不要使用只能充电的线。

### 3.3 指示灯与按键

| 部件 | 位置 | 作用 |
|------|------|------|
| 板载 LED ×2 | 每块 Pico 上 | 指示对应输出的活动状态、配置模式、固件写入等；可在配置页选择显示模式 |
| 键盘 LED | 键盘上 | 热键确认、配置模式提示；也可将 Caps Lock 用作输出指示 |
| BOOTSEL 按键 ×2 | 每块 Pico 上 | 固件恢复：按住后插入 USB，进入 `RPI-RP2` 引导模式 |
| USB-A 输入口 ×2 | PCB 一侧 | 连接键盘和鼠标 |
| USB 设备口 ×2 | 两块 Pico 上 | 连接两台电脑 |
| 电源开关 | 无 | 插入 USB 即上电，拔出即断电 |

> 部分 3D 打印外壳可能遮挡板载 LED。此时可以通过键盘 LED 的闪烁、配置页的"闪烁/双闪"按钮或热键反馈来判断设备状态。

### 3.4 硬件组成

| 部件 | 说明 |
|------|------|
| 主控 | 2 × Raspberry Pi Pico（RP2040） |
| 数字隔离器 | TI ISO7721DR（兼容型号亦可），设计隔离电压 2kV |
| USB-A 输入 | 2 个，用于键盘和鼠标 |
| USB 设备输出 | 2 个，分别连接两台电脑 |
| ESD 保护 | PCB v1.1 增加 TPD4E1U06 TVS 阵列 |
| USB 限流电阻 | PCB v1.1 增加 27Ω 电阻 |
| 滤波电容 | 100nF、4.7µF 等 |
| 外壳 | 3D 打印卡扣式，约 33g 耗材，无需螺丝 |
| 供电 | USB 总线供电，两块板分别由对应电脑供电 |

PCB v1.0 更适合手工焊接，v1.1 增加了 ESD 保护、VBUS 电容、27Ω USB 电阻和丝印方向标记。PCB v1.1 的物料成本约为 11.22 欧元（不含外壳、线缆和运费），具体以项目物料清单为准。

### 3.5 线缆与接口选择

- 使用**支持数据传输**的 USB 线，而不是只能充电的线。
- 优先使用质量可靠、长度适中的线缆；过长或劣质的线可能导致 USB 枚举不稳定。
- 如果电脑只有 USB-C 接口，可使用 USB-C 转 Micro-USB 数据线或转接头；如果 Pico 是 USB-C 版本，则使用 USB-C 转 USB-C 数据线。
- 如果使用 USB 扩展坞或集线器，请确认它能稳定提供 USB 数据和供电；出现识别问题时，优先直连电脑。
- 不要在同一台电脑上同时连接 A 端和 B 端；这会让两个输出指向同一台电脑，切换功能失去意义。

## 4. 安装与连接

### 4.1 安装前检查

1. 确认 Movio 已刷入固件。全新 DIY 主板需要先按第 10.2 节刷写 `movio.uf2`。
2. 确认两台电脑都能正常供电，且至少各有一个可用的 USB-A 或 USB-C 接口。
3. 确认键盘、鼠标是标准 USB HID 设备；无线键鼠应带有 USB 接收器。
4. 准备两根支持数据传输的 USB 线。
5. 如果需要修改配置，准备 Chrome、Chromium 或 Edge 浏览器。
6. 如果设备是 DIY 组装，先检查焊点、电源极性和是否有短路，再连接电脑。

### 4.2 连接步骤

1. **连接键盘**：将键盘插入带有键盘图标的 USB-A 输入口。
2. **连接鼠标**：将鼠标插入带有鼠标图标的 USB-A 输入口。
   - 如果使用键盘/鼠标合一的无线接收器，插入任一输入口通常都可以；若识别异常，优先插入键盘口。
3. **连接电脑 A**：用 USB 数据线把 Movio 的 A 端连接到电脑 A。
4. **连接电脑 B**：用另一根 USB 数据线把 Movio 的 B 端连接到电脑 B。
5. **打开两台电脑**：等待几秒钟，让两台电脑完成 USB 枚举。
6. **观察反馈**：插入键盘或鼠标时，板载 LED 和键盘 LED 应快速闪烁，表示设备已被检测到。
7. **测试切换**：移动鼠标，光标应出现在默认输出 A 上；把光标移到共享边缘并继续移动，应切换到输出 B。

> **注意**
>
> - 两台电脑都必须提供 USB 供电。只开一台电脑时，另一块板没有供电，双机切换无法正常工作。
> - 不要把键盘/鼠标插入 A/B 输出端，也不要把电脑插入 USB-A 输入口。
> - 首次上电默认活动输出为 A，光标初始位于 A 的左上角附近。
> - 如果电脑在关机或休眠时切断 USB 供电，Movio 也会随之断电；这是正常现象。

### 4.3 上电与自检

连接完成后，可以按以下顺序做一次简单自检：

1. 两台电脑都开机，并确认 Movio 的两个 USB 设备口都被电脑识别。
2. 插入键盘：如果两块板载 LED 都能看到，应该先后闪烁；这表示键盘被本地板识别，并且两块板之间的 UART 通信正常。
3. 插入鼠标：对应板载 LED 应闪烁。
4. 移动鼠标：光标应在输出 A 上移动。
5. 按 `左 Ctrl` + `Caps Lock`：光标和键盘应切换到输出 B，LED 指示随之变化。
6. 再按一次：应切回输出 A。
7. 按 `左 Ctrl` + `右 Shift` + `C` + `O`：应进入配置模式，键盘所在电脑上出现 `MOVIO` 盘。

如果自检中的某一步失败，请先查阅第 12 章"故障排查"，不要急于反复插拔或刷写固件。

### 4.4 安装验收清单

- [ ] 两台电脑都已开机，并为 Movio 提供 USB 供电。
- [ ] 键盘、鼠标均被识别，插入时 LED 有闪烁反馈。
- [ ] 光标可以在输出 A 上正常移动。
- [ ] 光标可以从 A 穿到 B，再从 B 穿回 A。
- [ ] 键盘输入跟随当前输出。
- [ ] `左 Ctrl` + `Caps Lock` 可以切换输出。
- [ ] 切换后光标高度基本一致；如不一致，已完成高度校准。
- [ ] 可以进入配置模式，并看到 `MOVIO` 盘和 `config.htm`。
- [ ] 配置页可以连接设备、读取和保存参数。
- [ ] 设备状态中显示的固件版本符合预期。

### 4.5 常见接线错误

| 错误 | 可能现象 | 正确处理 |
|------|----------|----------|
| 键盘/鼠标插到 A/B 输出端 | 电脑无法识别键鼠，或识别为其他设备 | 插到 USB-A 输入口 |
| 电脑插到 USB-A 输入口 | 电脑无法识别 Movio，键鼠无反应 | 插到 Pico 的 USB 设备口 |
| 使用充电线 | 设备不上电或无法枚举 | 更换为数据线 |
| 两根输出线都接同一台电脑 | 切换无效或光标异常 | 分别连接两台电脑 |
| 使用无供电的 USB 集线器 | 设备不稳定、掉线 | 直连电脑或使用带供电的集线器 |
| A/B 接反 | 切换方向与预期相反 | 在配置页对调"屏幕位置"，或交换两根线 |
| 只开一台电脑 | 另一块板不上电，双机切换无法工作 | 两台电脑都开机/供电 |

## 5. 首次配置

### 5.1 默认配置与出厂状态

Movio 首次上电或恢复默认配置后，大致处于以下状态（具体以设备读取值为准）：

| 配置项 | 默认值 |
|--------|--------|
| 活动输出 | 输出 A |
| 输出 A 屏幕数量 | 1 |
| 输出 B 屏幕数量 | 1 |
| 输出 A 屏幕位置 | 右 |
| 输出 B 屏幕位置 | 左 |
| 输出 A 操作系统 | macOS |
| 输出 B 操作系统 | Linux |
| 鼠标速度 X / Y | 16 / 28 |
| 上边界 / 下边界 | 0 / 32767 |
| 光标停靠位置 | 上 |
| 屏幕保护 | 禁用 |
| 跳转阈值 | 0 |
| 鼠标加速 | 开启 |
| 游戏模式默认开启 | 关闭 |
| 键盘 LED 作为状态灯 | 关闭 |
| 板载 LED | 显示活动输出 |

> 默认的操作系统和屏幕位置只是常见示例，并不代表您的实际环境。首次使用请务必按实际电脑修改，否则可能出现切换方向相反、多屏异常或系统锁定快捷键错误等问题。

### 5.2 确定 A/B 与屏幕方位

1. 查看 PCB 或外壳上的 A/B 丝印，确认哪一端连接哪台电脑。
2. 默认布局是 **A 在右、B 在左**：
   - 从 A 移向 B：把光标向左移；
   - 从 B 移向 A：把光标向右移。
3. 如果您的实际布局是 A 在左、B 在右，请在配置页把 A 的"屏幕位置"设为"左"，B 设为"右"。
4. 如果每台电脑有多块屏幕，**主屏应紧邻另一台电脑，扩展屏向外侧延伸**：

```text
   B3      B2      B1   │   A1      A2      A3
  扩展    扩展    主屏  │  主屏    扩展    扩展
                       │
                 共享边缘（跨电脑切换发生在这里）
```

> Movio 只支持**左右并排**布局，不支持上下堆叠。若两台电脑的屏幕是上下排列，Movio 无法按预期切换。

### 5.3 进入配置模式

1. 确认键盘已连接，并且设备处于正常模式。
2. 按住 `左 Ctrl` 和 `右 Shift`，然后依次按下 `C` 和 `O`。
3. 设备会重启并进入配置模式。
4. 在**键盘所连接的那台电脑**上，会出现一个名为 `MOVIO` 的 USB 存储盘。
   - 如果键盘接在 A 侧输入口，`MOVIO` 通常出现在电脑 A；
   - 如果键盘接在 B 侧输入口，`MOVIO` 出现在电脑 B。
5. 配置模式期间，板载 LED 和键盘 LED 会周期性闪烁。
6. 如果超过约 5 分钟没有配置操作，设备会自动退出配置模式并重启。

> **提示**：配置模式只会在键盘所在的那一侧启动，另一块板保持正常模式。配置页会通过板间通信把设置同步到另一块板，不需要分别连接两块板。

### 5.4 设置两台电脑

1. 打开 `MOVIO` 盘，双击 `config.htm`，使用 Chrome、Chromium 或 Edge 打开。
2. 点击页面左侧的"连接"，在浏览器弹窗中选择 Movio 设备并允许访问。
3. 连接成功后，页面会自动读取当前配置；如果没有自动读取，点击"读取"。
4. 在"输出 A"和"输出 B"两栏中分别设置：
   - **操作系统**：Windows / macOS / Linux / Android / 其他；
   - **屏幕数量**：该电脑实际连接的屏幕数（1–3）；
   - **屏幕位置**：该电脑在整体布局中的左/右位置；
   - **速度 X / 速度 Y**：鼠标移动速度，建议先保持默认；
   - **上边界 / 下边界**：屏幕高度校准值，建议先用快捷键校准；
   - **光标停靠位置**：上 / 下 / 上次位置，一般保持默认；
   - **屏幕保护**：默认禁用，需要时再开启。
5. 在"通用配置"中，建议首次保持默认：
   - 跳转阈值：0；
   - 启用加速：开启；
   - 游戏模式默认开启：关闭；
   - 强制鼠标启动模式、强制键盘启动协议、强制端口：关闭；
   - 板载 LED：显示活动输出。
6. 点击"保存"，等待保存完成。
7. 点击"退出"，设备重启回到正常模式。

> **建议**：第一次配置时先只设置"操作系统"和"屏幕位置"，确认基本切换正常，再调整多屏、速度、LED 和屏幕保护。这样更容易定位问题。

### 5.5 保存与退出

- **保存**：把当前配置写入两块板的 Flash。左侧菜单的"保存"和页面右下角的"保存"按钮效果相同。
- **退出**：让配置板重启回正常模式，`MOVIO` 盘消失。
- **自动退出**：约 5 分钟无配置操作后自动重启，未保存的修改会丢失。
- **再次按配置快捷键**：在配置模式中再次按 `左 Ctrl` + `右 Shift` + `C` + `O`，也会退出配置模式。
- **强制启动类选项**：修改"强制鼠标启动模式""强制键盘启动协议""强制端口"后，需要重启设备或重新插拔键鼠才会生效。

### 5.6 校准屏幕高度

如果两台电脑的显示器尺寸、分辨率或垂直位置不同，切换后光标高度可能不一致。校准方法：

1. 先切换到**较大屏幕**所在的那台电脑，再把鼠标移到该屏幕上。
2. 将光标停留在与较小屏幕**顶边**对应的高度。
3. 按 `右 Shift` + `F12` + `Y`。板载 LED 和键盘 LED 会闪烁确认。
4. 如果需要校准底边，把光标移到与较小屏幕**底边**对应的高度，再按一次 `右 Shift` + `F12` + `Y`。
5. 校准值会保存到 Flash，并同步到两块板，后续切换自动生效。

![屏幕高度校准](../img/border_top_s.png)

*图 4：把光标停在与较小屏幕顶边对应的高度，然后按校准快捷键*

> **说明**
>
> - 光标位于屏幕上半部分时，快捷键记录"上边界"；位于下半部分时，记录"下边界"。
> - 如果两块屏幕尺寸相同，边界值应保持为 0 和 32767；如果误校准，可在配置页手动改回，或使用"清除配置"恢复默认。
> - 校准值保存在两块板上，之后更换显示器或调整显示器位置时，需要重新校准。

### 5.7 推荐配置场景

| 场景 | 输出 A | 输出 B | 说明 |
|------|--------|--------|------|
| 两台电脑各一块屏 | 屏幕数 1，位置右 | 屏幕数 1，位置左 | 最常见；先确认这个场景 |
| A 双屏、B 单屏 | 屏幕数 2，位置右 | 屏幕数 1，位置左 | A 的主屏在左，扩展屏在右 |
| 两台电脑各双屏 | 屏幕数 2，位置右 | 屏幕数 2，位置左 | 主屏在中间，扩展屏向外 |
| Linux 多显示器 | 屏幕数 1 | 屏幕数 1 | Linux 通常把所有显示器视为一个虚拟桌面 |
| 游戏/虚拟机 | 屏幕数 1 | 屏幕数 1 | 开启游戏模式，使用相对鼠标 |

## 6. 日常使用

### 6.1 鼠标穿屏

- 把光标移到两台电脑共享的边缘，继续朝另一台电脑的方向移动，光标就会穿过去。
- 光标穿屏时，设备会保持或按校准值缩放 Y 坐标，并从另一侧边缘出现。
- 切换方向取决于"屏幕位置"配置：

| 实际布局 | 从 A 到 B | 从 B 到 A |
|----------|-----------|-----------|
| A 在右、B 在左 | 向左移 | 向右移 |
| A 在左、B 在右 | 向右移 | 向左移 |

- **按住鼠标按键时不会跨电脑切换**。这是为了避免拖拽文件或窗口时误切换。松开按键后再移动即可。
- **不支持跨电脑拖拽文件或窗口**。同一台电脑内部的多屏拖拽不受影响。
- 如果光标到达边缘后不切换，可能是跳转阈值过大、开启了游戏模式或切换锁定、屏幕位置配置错误，或当前不在主屏上。请参阅第 12 章。

### 6.2 键盘跟随与独立切换

- 默认情况下，键盘跟随当前活动输出：鼠标切换到哪台电脑，键盘输入就发送到哪台电脑。
- 也可以按 `左 Ctrl` + `Caps Lock` 独立切换输出；切换后鼠标和键盘一起过去。
- 切换输出时，设备会释放所有按键，避免在另一台电脑上出现"按键卡住"。
- 如果您在按住某个键时切换输出，该按键可能会被释放；到达另一台电脑后需要重新按下。
- 键盘上的媒体键、音量键等标准 Consumer Control 按键通常也会跟随当前输出。

![键盘输入跟随](../img/demo-typing.gif)

*图 5：键盘输入自动跟随当前输出*

### 6.3 多显示器

- 每台电脑的主屏应紧邻另一台电脑，扩展屏向外侧延伸。
- 在同一台电脑内：
  - 从主屏向**外侧**移动，可切换到扩展屏；
  - 从扩展屏向**内侧**移动，可回到主屏。
- 在 Windows 和 macOS 上，多屏切换会使用兼容模式（相对鼠标或额外移动），光标手感可能与单屏略有不同。
- 在 Linux 上，建议把"屏幕数量"保持为 1，由桌面环境管理多显示器；只有确实需要 Movio 参与多屏切换时才设为多屏。
- Web 页面提供每路 1–3 块屏幕的选项，两台电脑合计最多 6 块。

> 如果多屏切换异常，先把两台电脑的"屏幕数量"都设为 1，确认基本穿屏正常，再逐台增加屏幕数量并测试。

### 6.4 光标停靠位置

"光标停靠位置"控制**跨电脑切换时**旧屏幕光标的停靠高度：

| 选项 | 行为 |
|------|------|
| 上 | 旧光标停靠到屏幕右侧边缘的顶部 |
| 下 | 旧光标停靠到屏幕右侧边缘的底部 |
| 上次位置 | 旧光标停靠到屏幕右侧边缘的当前高度 |

- 一般保持默认"上"即可。
- 如果在切换瞬间看到旧屏幕上的光标位置不自然，可以尝试"下"或"上次位置"。
- 该选项只影响跨电脑切换，不影响同一台电脑内主屏/扩展屏切换。

### 6.5 拖拽与鼠标按键

- 标准鼠标的左键、右键、中键、滚轮、横向滚动和侧键通常会正常转发。
- 厂商自定义按键、宏、RGB 控制等需要厂商驱动的功能，Movio 无法转发，可能无效。
- 在共享边缘按住按键时，跨电脑切换会被阻止；这是为了避免拖拽过程中误切换。
- 如果出现鼠标按键"卡住"，先松开按键、切换一次输出，或重新插拔鼠标；若仍复现，请更新固件。

### 6.6 休眠、唤醒与开机

- Movio 由两台电脑的 USB 口供电。部分电脑在休眠或关机时会切断 USB 供电，此时 Movio 会离线。
- 电脑唤醒后，等待几秒钟让 USB 重新枚举；如果键鼠无响应，重新插拔 Movio 的 USB 线或切换一次输出。
- 要唤醒另一台电脑，可以先用 `左 Ctrl` + `Caps Lock` 切换到该输出，然后移动鼠标或按键盘。
- 开机时默认活动输出为 A。如果要在 BIOS/UEFI 中操作另一台电脑，可先切换输出，或在配置页开启"强制键盘启动协议"。
- 设备没有电源开关，插拔 USB 即上电/断电。

### 6.7 使用建议

- 保持 USB 线和接口不受外力拉扯，避免频繁热插拔造成接口松动。
- 固件升级期间不要断电或拔线。
- 修改配置后先"保存"再"退出"；重要配置建议截图记录。
- 如果经常玩游戏或使用虚拟机，可在配置页开启"游戏模式默认开启"。
- 如果经常拖拽窗口，建议在跨屏前松开鼠标按键，避免在边缘被阻止。
- 定期检查项目 Release，获取兼容性和稳定性更新。

## 7. 快捷键

### 7.1 配置类快捷键

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 进入配置模式 | `左 Ctrl` + `右 Shift` + `C` + `O` | 设备重启，键盘侧出现 `MOVIO` 盘；在配置模式中再次按下可退出 |
| 重置配置 | `右 Shift` + `F12` + `D` | 立即清除两块板的配置并恢复默认值，无二次确认 |
| 保存屏幕高度偏移 | `右 Shift` + `F12` + `Y` | 把当前光标高度记录为上边界或下边界，并保存到 Flash |

> **警告**：`右 Shift` + `F12` + `D` 会立即清除配置，包括操作系统、屏幕位置、速度和校准值。执行前请确认不需要保留当前配置。清除后需要重新配置。

### 7.2 使用类快捷键

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 切换输出 | `左 Ctrl` + `Caps Lock` | 键鼠一起切换到另一台电脑；受切换锁定影响 |
| 游戏模式 | `左 Ctrl` + `右 Shift` + `G` | 鼠标切换为相对模式，鼠标不再穿屏；未开启切换锁定时，键盘快捷键仍可切换 |
| 屏幕保护：弹球 | `左 Ctrl` + `右 Shift` + `S` | 在当前输出启用 Pong 模式；临时生效，不写入 Flash |
| 屏幕保护：抖动 | `左 Ctrl` + `右 Shift` + `J` | 在当前输出启用 Jitter 模式；临时生效，不写入 Flash |
| 关闭屏幕保护 | `左 Ctrl` + `右 Shift` + `X` | 关闭当前输出的屏幕保护；临时生效 |
| 慢速鼠标 | `右 Ctrl` + `右 Alt` | 鼠标速度约降至原来的 1/4，便于精确定位；再次按下恢复 |
| 切换锁定 | `右 Ctrl` + `K` | 禁止鼠标穿屏和快捷键切换；再次按下解锁；重启后失效 |
| 锁定两台电脑 | `右 Ctrl` + `L` | 向两台电脑发送系统锁定快捷键（Windows/Linux 为 `Win+L`，macOS 为 `Ctrl+Cmd+Q`） |

> **注意**
>
> - "锁定两台电脑"不是禁止切换，而是锁定两台电脑的操作系统会话。需要先在配置页正确设置两台电脑的操作系统；Linux 桌面环境的锁定快捷键可能不同，部分环境可能无效。
> - "切换锁定"只影响 Movio 的切换行为，不会锁定电脑系统。
> - 游戏模式下，鼠标不会因移动到边缘而切换；未开启切换锁定时，`左 Ctrl` + `Caps Lock` 仍可切换输出。

### 7.3 按键说明与冲突

- 组合键需要**同时按住**修饰键并按下对应按键。例如 `左 Ctrl` + `右 Shift` + `C` + `O`：先按住左 Ctrl 和右 Shift，再依次按下 C 和 O（按 O 时 C 可以仍按住）。
- 部分薄膜键盘存在按键冲突（Ghosting），无法同时上报多个按键，导致快捷键不触发。建议使用支持 6KRO/NKRO 的键盘，或调整按键顺序。
- 除"慢速鼠标"外，上述快捷键默认会被设备拦截，不会发送到电脑；因此不会在操作系统中输入这些组合。
- 如果某个应用使用了相同组合键（例如 `Ctrl+Shift+S`），该应用将收不到这个快捷键；这是正常现象。
- Caps Lock 单独按下仍然正常工作；只有与 `左 Ctrl` 同时按下时才会被识别为切换快捷键。
- 快捷键目前不能在 Web 配置页中修改；需要修改时要在源码 `src/include/user_config.h` 中重新编译固件。

### 7.4 操作反馈

- 大多数快捷键执行后，板载 LED 和键盘 LED 会快速闪烁约 0.4 秒（2–3 次），表示操作已被识别。
- 进入配置模式后，LED 会周期性闪烁，直到退出。
- 固件写入期间，板载 LED 会持续闪烁；键盘 LED 不保证同步闪烁。
- 如果没有看到任何反馈，请检查键盘是否被识别、组合键是否按对、键盘是否支持多键同时上报。

## 8. Web 配置页

### 8.1 进入与退出配置模式

**进入：**

1. 确认键盘已连接，设备处于正常模式。
2. 按住 `左 Ctrl` 和 `右 Shift`，依次按下 `C` 和 `O`。
3. 设备重启，键盘所连接的那台电脑上出现 `MOVIO` 盘。
4. 配置模式期间，板载 LED 和键盘 LED 会闪烁。

**退出：**

- 在配置页点击"退出"；或
- 在配置模式中再次按 `左 Ctrl` + `右 Shift` + `C` + `O`；或
- 等待约 5 分钟无操作，设备自动退出。

> `MOVIO` 盘只会在键盘所在的那一侧出现。如果键盘接在 B 侧输入口，请到电脑 B 上查找该盘。

### 8.2 连接设备

1. 打开 `MOVIO` 盘中的 `config.htm`。
2. 使用 Chrome、Chromium 或 Edge 打开；不要使用 Firefox 或 Safari。
3. 点击左侧"连接"。
4. 浏览器会弹出 HID 设备选择窗口，选择 Movio 设备并点击"连接"。
5. 连接成功后，页面会自动读取配置；如果没有，点击"读取"。

> 如果弹窗中没有设备，请确认设备处于配置模式、浏览器支持 WebHID、Linux 已配置 udev 规则，并且没有其他标签页占用设备。详见第 12.5 节。

### 8.3 界面与按钮

配置页主要分为：

- 左侧操作菜单；
- 中间"输出 A"和"输出 B"两栏；
- 下方"通用配置"；
- 右侧"设备状态"和"保存"按钮；
- 右上角 `EN / 中文` 语言切换。

```text
│ 闪烁 / 双闪  │ 操作系统、位置、停靠 │ 操作系统、位置、停靠 │
│ 引导 / 清除  │ 屏幕保护             │ 屏幕保护             │
├──────────────┴──────────────────────┴──────────────────────┤
│ 通用配置：鼠标 / 键盘 / 强制端口 / 板载 LED                 │
├─────────────────────────────┬───────────────────────────────┤
```

| 按钮 | 功能 |
|------|------|
| 连接 | 通过 WebHID 连接 Movio 设备 |
| 读取 | 从设备读取当前所有配置值 |
| 保存 | 把当前配置写入两块板的 Flash |
| 退出 | 重启设备，退出配置模式 |
| 闪烁 | 让当前配置板的板载 LED 闪烁，用于识别设备 |
| 双闪 | 让两块板的板载 LED 同时闪烁 |
| 引导模式 | 让两块板进入 BOOTSEL 引导模式，出现 `RPI-RP2` 盘；用于手动刷写或恢复 |

- 按钮点击后通常会显示"✓ 已执行"，1 秒后恢复。

- 语言切换会记住您的选择（保存在浏览器本地存储中），默认中文。
- 配置页完全在本地运行，不加载外部资源，也不会上传数据。

### 8.4 输出 A / 输出 B 配置

以下配置对每台电脑分别生效。默认值以当前 main 分支代码为准，实际以设备读取值为准。

| 配置项 | 范围/选项 | 默认值 | 说明 |
|--------|-----------|--------|------|
| 屏幕数量 | 1 / 2 / 3 | 1 | 该电脑连接的屏幕数量；主屏应紧邻另一台电脑 |
| 速度 X | 1–100 | 16 | 鼠标水平方向速度；数值越大移动越快 |
| 速度 Y | 1–100 | 28 | 鼠标垂直方向速度；数值越大移动越快 |
| 上边界 | 0–32767 | 0 | 屏幕高度校准的上边界；建议用快捷键校准 |
| 下边界 | 0–32767 | 32767 | 屏幕高度校准的下边界；建议用快捷键校准 |
| 操作系统 | Linux / macOS / Windows / Android / 其他 | A：macOS；B：Linux | 影响系统锁定快捷键和多屏兼容逻辑，必须按实际设置 |
| 屏幕位置 | 左 / 右 | A：右；B：左 | 该电脑在整体布局中的左/右位置，不是主屏在电脑内部的位置 |
| 光标停靠位置 | 上 / 下 / 上次位置 | 上 | 跨电脑切换时旧光标的停靠高度 |
| 屏幕保护模式 | 禁用 / 弹球 / 抖动 | 禁用 | 向电脑发送微小鼠标移动，防止休眠或锁屏 |
| 仅不活跃时 | 勾选/不勾选 | 不勾选 | 仅在当前输出不活跃时运行屏幕保护 |
| 空闲时间 (sec) | 秒 | 240 | 无输入多久后启动屏幕保护 |
| 最大时间 (sec) | 秒 | 0 | 屏幕保护最长运行时间；0 表示不限制 |

**关于屏幕数量：**

- 单屏电脑设为 1。
- 多屏电脑按实际数量设置；主屏必须紧邻另一台电脑，扩展屏向外侧排列。
- Linux 通常建议设为 1，由桌面环境管理多显示器。
- 如果多屏切换异常，先设为 1 验证基本功能。

**关于操作系统：**

- 必须按实际系统设置，否则"锁定两台电脑"可能发送错误的快捷键，多屏兼容逻辑也可能异常。
- "其他"用于未列出的系统；这类系统通常只能使用基本切换和游戏模式。

**关于边界值：**

- 0 表示屏幕顶部，32767 表示屏幕底部。
- 两台显示器尺寸相同时，保持 0 / 32767 即可。
- 尺寸或垂直位置不同时，使用 `右 Shift` + `F12` + `Y` 校准，比手动填写更可靠。

### 8.5 通用配置

| 配置项 | 默认值 | 说明 |

| 强制鼠标启动模式 | 关闭 | 用简单的 Boot 协议初始化鼠标，解决部分鼠标兼容问题；可能损失部分高级功能，仅在需要时开启 |

**板载 LED 模式说明：**

| 模式 | 行为 |

"设备状态"区域显示：

### 8.7 保存、生效与自动退出

- 修改输入框、下拉框或滑块后，松开滑块或离开输入框时，值会立即下发到设备。
- **只有点击"保存"后，配置才会写入 Flash**；否则重启或断电后恢复上一次保存的值。
- 保存会同时写入两块板。
- 点击"退出"后设备重启，`MOVIO` 盘消失。
- 约 5 分钟无配置操作，设备会自动退出配置模式。
- 修改"强制鼠标启动模式""强制键盘启动协议""强制端口"后，需要重启设备或重新插拔键鼠才会生效。
- 修改"游戏模式默认开启"后，需要重启设备才会生效。
- 修改 LED 模式、速度、跳转阈值、屏幕保护等通常立即生效。

> 保存后建议再点击一次"读取"，确认设备中的值确实已经更新。如果保存按钮显示"完成"但值没有变化，请检查是否连接了正确的设备，或重新进入配置模式。

### 8.8 Linux 权限（udev）

在 Linux 上，Chrome/Chromium 访问 HID 设备可能需要 udev 规则。配置模式下的设备 ID 是 `2e8a:107c`，而不是正常模式的 `1209:c000`；如果只添加正常模式规则，配置页可能看不到设备。

创建 `/etc/udev/rules.d/99-movio.rules`：

```udev
# Movio 正常模式（可选）
KERNEL=="hidraw*", SUBSYSTEM=="hidraw", ATTRS{idVendor}=="1209", ATTRS{idProduct}=="c000", TAG+="uaccess"

# Movio 配置模式（WebHID 需要）
KERNEL=="hidraw*", SUBSYSTEM=="hidraw", ATTRS{idVendor}=="2e8a", ATTRS{idProduct}=="107c", TAG+="uaccess"
```

然后重新加载规则并重新插拔设备：

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

如果您的系统不支持 `uaccess`，可以改用 `plugdev` 组：

```udev
KERNEL=="hidraw*", SUBSYSTEM=="hidraw", ATTRS{idVendor}=="2e8a", ATTRS{idProduct}=="107c", GROUP="plugdev", MODE="0660"
```

并确保当前用户在 `plugdev` 组中：

```bash
sudo usermod -aG plugdev "$USER"
```

修改组后需要注销并重新登录。重新插拔设备后，可在配置模式中用以下命令确认设备 ID：

```bash
lsusb | grep -E "2e8a:107c|1209:c000"
```

- 正常模式应显示 `1209:c000`；
- 配置模式应显示 `2e8a:107c`。

> 如果使用 Flatpak、Snap 等沙箱版浏览器，可能还需要授予 USB/HID 设备访问权限；必要时改用系统包管理器安装的 Chrome/Chromium。

### 8.9 浏览器兼容性

| 浏览器 | 支持 WebHID | 说明 |
|--------|-------------|------|
| Chrome | 是 | 推荐 |
| Chromium | 是 | 推荐 |
| Edge | 是 | 基于 Chromium，通常可用 |
| Firefox | 否 | 不支持 WebHID，无法连接设备 |
| Safari | 否 | 不支持 WebHID |

## 9. 进阶功能

### 9.1 屏幕高度与多屏布局

**高度校准的适用场景：**

- 两台显示器尺寸不同；
- 分辨率不同；
- 显示器垂直位置不同；
- 切换后光标明显偏上或偏下。

**校准步骤：**

1. 切换到**较大屏幕**所在的那台电脑。
2. 把光标停在与较小屏幕顶边对应的高度。
3. 按 `右 Shift` + `F12` + `Y`，LED 闪烁确认。
4. 把光标停在与较小屏幕底边对应的高度，再按一次。
5. 来回切换几次，确认高度一致。

**手动调整：**

- 上边界、下边界的范围为 0–32767。
- 0 是屏幕顶部，32767 是底部。
- 如果两台显示器完全相同，应保持上边界 0、下边界 32767。
- 手动修改后点击"保存"。

**多屏布局要点：**

```text
   B2      B1   │   A1      A2
  扩展    主屏  │  主屏    扩展
```

- 主屏是紧邻另一台电脑的那块屏幕；
- 扩展屏在主屏的外侧；
- 不要把扩展屏放在主屏和另一台电脑之间，否则切换逻辑会与视觉布局不一致；
- 每路通过 Web 页面可选 1–3 块屏幕，两台合计最多 6 块；
- Linux 通常设为 1；Windows/macOS 多屏使用兼容模式，可能需要多试几次。

### 9.2 游戏模式

**适用场景：**

- 游戏使用相对鼠标或 Raw Input；
- 虚拟机、远程桌面、旧系统不兼容绝对坐标；
- 某些应用在绝对坐标下光标漂移或无法点击；
- 需要临时禁止鼠标穿屏。

**使用方法：**

1. 按 `左 Ctrl` + `右 Shift` + `G` 开启游戏模式。
2. 鼠标切换为标准相对模式，移动不再受绝对坐标限制。
3. 鼠标移动到屏幕边缘不会切换输出。
4. 未开启切换锁定时，键盘快捷键 `左 Ctrl` + `Caps Lock` 仍可切换输出。
5. 再按一次 `左 Ctrl` + `右 Shift` + `G` 退出游戏模式。

**开机默认开启：**

- 在配置页勾选"游戏模式默认开启"，保存并退出。
- 设备下次启动时直接进入游戏模式。
- 适合以游戏/虚拟机为主的用户；日常办公时记得用快捷键退出。

> 游戏模式不会改变键盘、鼠标的 USB 描述符，仍然是标准 HID 设备；它只是改变 Movio 内部的坐标处理和切换逻辑。

### 9.3 慢速鼠标

- 按 `右 Ctrl` + `右 Alt` 切换慢速鼠标模式。
- 鼠标速度约降至原来的 1/4，适合精确定位、拖动视频进度条、绘图等。
- 再次按同一组合键恢复正常速度。
- 该状态不会写入 Flash，重启后恢复默认速度。
- 该快捷键会把修饰键传递给电脑（`pass_to_os`），因此某些应用可能同时收到 `Ctrl+Alt`；如果遇到冲突，可改用降低"速度 X/Y"的方式。

### 9.4 切换锁定与系统锁定

Movio 有两个容易混淆的"锁定"功能：

| 功能 | 快捷键 | 作用 | 是否持久 |
|------|--------|------|----------|
| 切换锁定 | `右 Ctrl` + `K` | 禁止鼠标穿屏和快捷键切换，防止误切换 | 否，重启失效 |
| 锁定两台电脑 | `右 Ctrl` + `L` | 向两台电脑发送系统锁定快捷键，锁定操作系统会话 | 否，仅执行一次 |

**切换锁定：**

- 开启后，鼠标到边缘不会切换，`左 Ctrl` + `Caps Lock` 也不会切换。
- 再次按 `右 Ctrl` + `K` 解锁。
- 适合临时需要固定在一台电脑上的场景。

**锁定两台电脑：**

- Windows/Linux：发送 `Win+L`；
- macOS：发送 `Ctrl+Cmd+Q`；
- 需要先在配置页正确设置两台电脑的操作系统；
- Linux 不同桌面环境的锁定快捷键可能不同，部分环境可能无效；
- 该功能不会阻止您之后切换输出，也不会记住锁定状态。

### 9.5 屏幕保护

Movio 的"屏幕保护"并不是显示器屏保，而是**向电脑发送微小的鼠标移动**，防止电脑进入休眠、锁屏或屏保。它不会产生鼠标点击。

**模式：**

| 模式 | 行为 |
|------|------|
| 禁用 | 不发送任何自动移动 |
| 弹球 (Pong) | 光标像弹球一样在屏幕上移动，约每 5ms 更新一次 |
| 抖动 (Jitter) | 每隔约 10 秒做一次极轻微移动（约 2 个坐标单位） |

**配置项：**

- **仅不活跃时**：勾选后，只有当该输出不是当前活动输出时才运行；适合"我在用 A 时，让 B 不要锁屏"。
- **空闲时间 (sec)**：该输出无输入多久后启动，默认 240 秒。
- **最大时间 (sec)**：屏幕保护最长运行时间；0 表示不限制。超过时间后停止发送移动。

**快捷键：**

- `左 Ctrl` + `右 Shift` + `S`：在当前输出启用弹球；
- `左 Ctrl` + `右 Shift` + `J`：在当前输出启用抖动；
- `左 Ctrl` + `右 Shift` + `X`：关闭当前输出的屏幕保护。

> 快捷键启用/关闭是**临时**的，不会写入 Flash；需要持久化请在配置页设置并保存。屏幕保护会阻止电脑休眠，可能增加功耗，请按需使用。

### 9.6 板载 LED 与键盘 LED 指示

**板载 LED：**

- 每块 Pico 各有一个板载 LED，对应一个输出。
- 可在配置页选择"显示活动输出""短空闲 (1 秒)""长空闲 (2 分钟)""仅状态闪烁""禁用"。
- 默认"显示活动输出"：当前活动输出对应的 LED 常亮。
- 如果外壳遮挡 LED，可改用键盘 LED 指示。

**键盘 LED 作为状态灯：**

- 启用后，Caps Lock 灯不再表示大写锁定，而是表示当前输出：
  - **亮 = 输出 B 正在使用**；
  - **灭 = 输出 A 正在使用**。
- Num Lock、Scroll Lock 灯仍按系统状态显示。
- 这会覆盖 Caps Lock 原本的指示灯含义；键盘实际的大写状态仍可能存在，但指示灯不再反映它，请以输入结果为准。如果您需要 Caps Lock 指示，请不要开启此选项。
- 热键确认、配置模式时，键盘 LED 仍会临时闪烁；固件写入时以板载 LED 为准。

### 9.7 鼠标加速与跳转阈值

**鼠标加速：**

- 默认开启。设备根据移动速度自动放大位移，慢速移动更精细，快速移动更快。
- 如果觉得光标"飘"或瞄准不稳定，可以在配置页关闭"启用加速"，获得更线性的手感。
- 关闭加速后，速度只由"速度 X/Y"决定。

**跳转阈值：**

- 范围 0–3000，默认 0。
- 只影响**跨电脑切换**，不影响同一台电脑内的主屏/扩展屏切换。
- 0 表示光标到达边缘即可切换；数值越大，需要越用力地"推"过边缘。
- 如果经常误切换，可设置为 200–500；如果切换困难，设为 0。
- 该值是两个输出共用的通用配置。

**速度 X / Y：**

- 范围 1–100，默认 X=16、Y=28。
- 数值越大，鼠标移动越快。
- 两台电脑的屏幕比例或 DPI 不同时，可以分别调整，使手感接近。
- 建议先保持默认，确认切换正常后再微调。

### 9.8 BIOS/UEFI 与 BitLocker

- Movio 可以在 BIOS/UEFI 设置界面和 BitLocker 预启动界面使用，但部分主板对键盘协议的支持不同。
- 如果开机阶段键盘无响应：
  1. 先把输出切换到要操作的电脑（按 `左 Ctrl` + `Caps Lock`）；
  2. 在配置页开启"强制键盘启动协议"，保存并退出；
  3. 重启电脑再试。
- "强制键盘启动协议"会让键盘使用更简单的 Boot 协议，兼容性更好，但可能影响部分高级键功能。
- 如果要在 BIOS 中操作 B 电脑，记得先切换输出；设备上电默认活动输出为 A。
- 修改强制启动类选项后，需要重启设备或重新插拔键鼠才会生效。

## 10. 固件升级

### 10.1 版本与文件

- 仓库 `VERSION` 当前为 **0.80**，main 分支还包含 v0.80 之后的改进；配置结构版本为 8。
- 固件文件名为 `movio.uf2`，两块 Pico 使用**同一个文件**，不需要区分 A/B 版本。
- 从 [GitHub Releases](https://github.com/likeaturtle/Movio/releases) 下载最新版本。
- 如果 Release 提供 `checksums.txt` 或 SHA256，建议先校验文件完整性。
- 升级前建议记录当前配置页截图；重大版本升级后配置可能恢复默认。

> 只使用 `.uf2` 文件。不要复制 `.elf`、`.bin` 或其他文件到 `MOVIO` 盘；虚拟盘只识别 UF2 数据块，其他文件不会生效。

### 10.2 首次刷写（全新 DIY 主板）

全新 Pico 或空白主板没有 Movio 固件，需要先通过 ROM Bootloader 刷写：

1. 准备 `movio.uf2`。
2. 断开键盘、鼠标和另一侧 USB 线，只把要刷写的那块 Pico 连接到电脑。
3. 按住该 Pico 上的 **BOOTSEL** 按钮。
4. 把 Pico 的 USB 线插入电脑，保持按住 BOOTSEL，直到电脑出现名为 `RPI-RP2` 的 U 盘。
5. 松开 BOOTSEL。
6. 把 `movio.uf2` 复制到 `RPI-RP2` 盘。
7. 等待板子自动重启，`RPI-RP2` 盘消失。
8. 对另一块 Pico 重复步骤 3–7。
9. 两块板都刷写完成后，重新连接键盘、鼠标和两台电脑。
10. 首次启动后按第 5 章进行配置。

> - 标准 Pico 使用 Micro-USB；如果您的 Pico 是 USB-C 版本，请使用对应的数据线。
> - 如果外壳遮挡了 BOOTSEL 按钮，需要先打开外壳再操作。
> - 两块板刷写同一个 `movio.uf2`，板角色（A/B）由硬件自动探测。
> - 如果 `RPI-RP2` 没有出现，检查 BOOTSEL 是否按住、线缆是否为数据线、USB 口是否正常。

### 10.3 常规升级（通过 MOVIO 盘）

适用于已经能正常运行 Movio 固件的设备：

1. 保持两台电脑开机，并保持 A/B 两端都连接、供电稳定。
2. 按 `左 Ctrl` + `右 Shift` + `C` + `O` 进入配置模式。
3. 在键盘侧电脑上打开 `MOVIO` 盘。
4. 把新的 `movio.uf2` 复制到 `MOVIO` 盘根目录。
5. 复制过程中板载 LED 会闪烁；等待复制完成。键盘 LED 不保证同步闪烁。
6. 当前板会先写入固件并重启，然后通过板间通信把固件同步到另一块板。
7. 两块板的板载 LED 都停止闪烁、设备重新枚举后，升级完成。
8. 重新进入配置模式，在"设备状态"中确认版本号。

> **升级期间不要：**
>
> - 拔掉 USB 线或关闭电脑；
> - 格式化 `MOVIO` 盘；
> - 向盘中复制其他文件；
> - 强制断电或反复插拔。
>
> 只需要向一块板复制固件，另一块板会在检测到对方版本更新后自动同步。两台电脑都连接时升级最稳妥。

### 10.4 引导模式与恢复

如果 `MOVIO` 盘升级失败、设备无法正常启动，或需要手动降级，可使用引导模式恢复：

**方法一：配置页"引导模式"**

1. 进入配置模式并连接配置页。
2. 点击"引导模式"。
3. 两块板会重启进入 BOOTSEL，电脑上出现 `RPI-RP2` 盘（可能一次出现两个，也可能逐个出现）。
4. 把 `movio.uf2` 分别复制到每个 `RPI-RP2` 盘。
5. 等待板子重启，重新连接并配置。

**方法二：物理 BOOTSEL**

1. 断开所有 USB 线。
2. 按住一块 Pico 的 BOOTSEL，插入 USB 线。
3. 出现 `RPI-RP2` 后松开，复制 `movio.uf2`。
4. 等待重启，对另一块重复。
5. 两块板刷写同一版本后，重新连接。

> RP2040 的 ROM Bootloader 无法被固件擦除，因此只要硬件没有损坏，通常都可以通过 BOOTSEL 恢复。恢复后配置可能被重置，需要重新设置。

### 10.5 升级注意事项

- **供电稳定**：升级时两台电脑都应开机；不要使用不稳定的 USB 集线器或延长线。
- **版本匹配**：两块板应运行同一版本。如果一块板升级失败，建议两块都重新刷写同一版本，而不是只刷一块。
- **配置兼容**：配置结构版本变化时，设备会自动恢复默认配置；升级后请检查操作系统、屏幕位置、屏幕数量和边界值。
- **降级**：自动同步只会在对方版本更新时触发，不会自动降级。如需降级，请分别用 BOOTSEL 刷写两块板。
- **完整性**：固件使用 CRC32 校验，不是密码学签名；请从可信来源下载，避免使用来路不明的固件。
- **记录**：升级前记录当前版本和配置；升级后确认版本和基本功能。

### 10.6 验证与故障处理

**验证：**

1. 进入配置模式，连接配置页。
2. 查看"设备状态"中的"当前固件版本"和"当前固件校验值"。
3. 两块板应显示相同版本。
4. 测试鼠标穿屏、键盘跟随、快捷键和配置保存。

**升级失败的处理：**

| 现象 | 处理 |
|------|------|
| 复制后没有反应 | 确认文件是 `movio.uf2`，重新进入配置模式再试 |
| 只有一块板升级 | 保持两台电脑连接，等待自动同步；或分别用 BOOTSEL 刷写 |
| 升级后无法启动 | 断开电源，用 BOOTSEL 重新刷写两块板 |
| 升级后配置丢失 | 配置版本变化导致恢复默认；重新配置 |
| 版本号不变 | 确认复制的是新文件；检查另一块板是否完成同步 |
| `MOVIO` 盘不出现 | 参考第 12.5 节；必要时用 BOOTSEL 恢复 |

## 11. 状态指示与自检

### 11.1 板载 LED

板载 LED 的行为取决于配置页中的"板载 LED"模式：

| 模式 | 现象 |
|------|------|
| 显示活动输出 | 当前活动输出对应的 LED 常亮，另一块灭 |
| 短空闲 (1 秒) | 当前输出为活动输出且有输入时亮，停止输入约 1 秒后灭 |
| 长空闲 (2 分钟) | 当前输出为活动输出且有输入时亮，停止输入约 2 分钟后灭 |
| 仅状态闪烁 | 平时灭，状态事件时闪烁 |
| 禁用 | 不亮 |

此外，以下事件会触发板载 LED 闪烁：

- 插入键盘或鼠标被识别；
- 快捷键执行成功；
- 进入配置模式；
- 固件写入（板载 LED）；
- 配置页点击"闪烁"或"双闪"。

### 11.2 键盘 LED

- 大多数快捷键执行后，键盘 LED 会快速闪烁 2–3 次。
- 配置模式期间，键盘 LED 会周期性闪烁。
- 固件写入期间，以板载 LED 闪烁为主，键盘 LED 不保证同步闪烁。
- 如果开启"键盘 LED 作为状态灯"：
  - Caps Lock 灯亮 = 当前输出 B；
  - Caps Lock 灯灭 = 当前输出 A。

### 11.3 闪烁含义速查

| 现象 | 含义 |
|------|------|
| 插入键鼠后快速闪烁 2–3 次 | 设备已被识别 |
| 按快捷键后快速闪烁 | 快捷键已被接受 |
| 配置模式期间周期性闪烁 | 设备处于配置模式 |
| 板载 LED 在固件写入期间持续闪烁 | 正在写入或同步固件 |
| 当前输出对应的板载 LED 常亮 | 正常，处于"显示活动输出"模式 |
| 所有 LED 都不亮 | 可能未供电、LED 被禁用或设备未启动 |
| 插入键盘后两块板先后闪烁 | USB 识别和板间通信均正常 |

### 11.4 双板通信自检

如果能看到两块板的 LED，可以用以下方法快速判断故障范围：

1. 两台电脑都开机，A/B 两端都连接。
2. 把键盘插入键盘口。
3. 观察两块板的 LED：
   - **两块都闪**：键盘被本地板识别，且两块板之间的 UART 通信正常；
   - **只有一块闪**：本地 USB 识别正常，但另一块板没有收到消息，可能是另一块板未供电、UART/隔离器问题或焊接问题；
   - **两块都不闪**：键盘没有被识别，检查键盘、USB 口、线缆或供电。

鼠标也可以用同样方法测试。

> 如果外壳遮挡了板载 LED，可以通过键盘 LED 闪烁、配置页"双闪"或热键反馈来间接判断。DIY 主板如果只有一块闪，请检查数字隔离器、UART 引脚和电源焊接。

### 11.5 版本检查

- 进入配置模式，连接配置页，查看"设备状态"。
- "当前固件版本"应显示为 `v0.80` 这类格式。
- "当前固件校验值"可用于比对两块板是否运行同一固件。
- 如果两块板版本不同，建议重新升级或分别用 BOOTSEL 刷写同一版本。

## 12. 故障排查

### 12.1 排查顺序

建议按以下顺序排查，每次只改变一个变量：

1. **供电与线缆**：两台电脑是否开机、USB 口是否供电、线缆是否为数据线。
2. **键鼠识别**：键盘/鼠标是否被 Movio 识别，LED 是否有反馈。
3. **切换配置**：操作系统、屏幕位置、屏幕数量、跳转阈值、游戏/锁定状态。
4. **配置页**：浏览器、WebHID、udev、配置模式。
5. **固件**：版本是否一致、升级是否完成。
6. **系统兼容性**：Windows/macOS 多屏、BIOS、无线接收器。
7. **硬件**：DIY 主板检查焊接、隔离器、供电；成品联系售后。

### 12.2 电源与连接问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 设备完全无反应，LED 不亮 | 两台电脑未供电、线缆是充电线、USB 口无电 | 确认两台电脑开机；更换数据线；换一个 USB 口 |
| 只有一侧有反应 | 另一侧电脑未开机、USB 口不供电、线缆损坏 | 检查另一侧供电和线缆 |
| 设备时好时坏 | 线缆接触不良、USB 集线器供电不足 | 更换线缆；直连电脑；使用带供电的集线器 |
| 电脑无法识别 Movio | 插错口、线缆问题、Pico USB 口损坏 | 确认插在 A/B 端而不是 USB-A 输入口；换线/换口 |
| 设备明显过热、有异味 | 供电异常或硬件故障 | 立即断开所有 USB，停止使用并检查 |

### 12.3 键鼠识别问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 键盘无反应 | 插错口、键盘不兼容、线缆/接收器问题 | 插到键盘口；换键盘测试；开启"强制键盘启动协议" |
| 鼠标无反应 | 插错口、鼠标不兼容、接收器问题 | 插到鼠标口；换鼠标测试；开启"强制鼠标启动模式" |
| 无线键鼠不工作 | 接收器未配对、电池不足、USB 干扰 | 重新配对；换电池；用延长线把接收器远离干扰源 |
| 组合接收器只识别一个设备 | 接收器兼容性、枚举顺序 | 重新插拔；优先插键盘口；更新固件；开启兼容选项 |
| 键盘只在一台电脑上工作 | 板间通信、另一块板未供电、配置问题 | 检查两侧供电和线缆；观察双板 LED；更新固件 |
| 热键不触发 | 键盘按键冲突、组合键按错、键盘不支持多键 | 换 NKRO/6KRO 键盘；放慢按键顺序；确认组合键 |
| 媒体键/音量键无效 | 键盘使用非标准 HID、厂商自定义 | 换标准键盘测试；更新固件；部分高级键可能不支持 |

### 12.4 切换与光标问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 鼠标到边缘不切换 | 屏幕位置错误、跳转阈值过大、游戏模式/切换锁定、按住鼠标键、不在主屏 | 检查配置；把跳转阈值设为 0；退出游戏模式/解锁；松开鼠标键；回到主屏 |
| 切换方向相反 | A/B 接反或屏幕位置设置相反 | 在配置页对调"屏幕位置"，或交换 A/B 线 |
| 切换后光标高度不一致 | 屏幕尺寸/垂直位置不同，未校准 | 按 `右 Shift` + `F12` + `Y` 校准上/下边界 |
| 光标跳动或漂移 | 鼠标加速、速度过高、复合键盘、干扰 | 关闭加速；降低速度；更新固件；换 USB 口 |
| 光标卡在边缘 | 跳转阈值过大、游戏模式、切换锁定 | 降低阈值；退出游戏模式；解锁切换 |
| 键盘不跟随 | 切换失败、板间通信、配置错误 | 检查活动输出和 LED；切换一次；更新固件 |
| 按键卡住 | 切换时按键未释放、键盘/固件异常 | 切换一次输出；重新插拔键盘；更新固件 |
| 多屏切换异常 | 屏幕数量/位置错误、系统兼容性 | 先设为 1 屏验证；再逐台增加；确认主屏紧邻另一台电脑 |
| Windows 多屏异常 | KB5003637 等补丁限制绝对坐标 | 设为 1 屏；更新系统/固件；尝试游戏模式 |
| macOS 多屏异常 | macOS 多屏方案为实验性 | 设为 1 屏；更新固件；尝试重新切换 |
| 跨电脑拖拽失败 | 设计上不支持 | 这是正常行为；请在同一台电脑内拖拽，或使用其他方式传输文件 |

### 12.5 配置页问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 没有出现 `MOVIO` 盘 | 未进入配置模式、键盘侧不对、USB 问题、超时退出 | 重新按快捷键；到键盘所在电脑查找；检查线缆；重新进入 |
| 浏览器提示不支持 WebHID | 使用了 Firefox/Safari | 改用 Chrome、Chromium 或 Edge |
| 连接弹窗中没有设备 | Linux udev 未配置、设备不在配置模式、其他标签页占用 | 配置 udev；确认 `2e8a:107c`；关闭其他配置页；重新插拔 |
| 点击连接后无反应 | 浏览器权限被拒绝、设备被占用 | 允许 HID 权限；关闭其他使用设备的程序；重试 |
| 配置页看起来是压缩代码 | `config.htm` 是自解压页面 | 正常现象；用浏览器打开，不要用文本编辑器 |
| 配置值读取不到 | 未连接、连接了错误设备 | 重新连接；点击"读取"；确认设备处于配置模式 |
| 保存后值没有变化 | 未点击"保存"、自动退出、连接错误 | 点击"保存"并等待"完成"；重新读取；重新进入配置模式 |
| 修改强制启动选项无效 | 需要重启/重新插拔才生效 | 保存、退出、重启设备或重新插拔键鼠 |
| 配置页自动断开 | 5 分钟无配置操作自动退出 | 重新进入配置模式；每隔几分钟点击"读取"或修改一次配置 |
| 清除配置后无法切换 | 配置恢复默认，OS/位置不匹配 | 重新设置操作系统和屏幕位置 |

### 12.6 固件升级问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 复制 `movio.uf2` 失败 | 线缆/供电不稳定、盘被占用 | 换线/换口；关闭占用程序；重新进入配置模式 |
| 升级后只有一块板更新 | 另一块板未连接/未供电、同步未完成 | 保持两台电脑连接等待；或分别 BOOTSEL 刷写 |
| 升级后无法启动 | 文件损坏、断电、写入失败 | 用 BOOTSEL 重新刷写两块板 |
| 版本号不变 | 复制了旧文件、未完成同步 | 确认文件版本；重新复制；检查两块板 |
| 升级后配置丢失 | 配置结构版本变化，自动恢复默认 | 重新配置；升级前记录配置 |
| `RPI-RP2` 不出现 | BOOTSEL 未按住、线缆问题 | 重新按住 BOOTSEL 插线；换数据线/USB 口 |

### 12.7 系统兼容性问题

| 系统/场景 | 问题 | 处理 |
|-----------|------|------|
| Windows 10 多屏 | KB5003637 等补丁限制绝对坐标 | 设为 1 屏；更新固件/系统；尝试游戏模式 |
| macOS 多屏 | 多屏方案为实验性 | 设为 1 屏；更新固件；重新切换 |
| Linux 配置页 | 浏览器看不到设备 | 配置 udev，使用 `2e8a:107c` 规则 |
| Linux 系统锁定 | `Win+L` 在部分桌面环境无效 | 使用桌面环境自己的锁定快捷键 |
| Android | 多屏/绝对坐标支持有限 | 使用单屏；尝试游戏模式；确认 OTG 支持 |
| BIOS/UEFI | 键盘无响应 | 切换输出；开启"强制键盘启动协议"；重启 |
| BitLocker 预启动 | 键盘无响应 | 开启"强制键盘启动协议"；切换输出；重启 |
| 游戏/虚拟机 | 绝对鼠标不兼容 | 开启游戏模式 |

### 12.8 复位与恢复

**软复位：**

1. 断开 Movio 与两台电脑的 USB 线。
2. 等待 5 秒。
3. 重新连接两台电脑，等待枚举。
4. 重新测试键鼠。

**恢复默认配置：**

- 按 `右 Shift` + `F12` + `D`；或
- 在配置页点击"清除配置"。

> 恢复默认配置不会删除固件，只会清除设置。之后需要重新设置操作系统、屏幕位置和屏幕数量。

**恢复固件：**

- 使用物理 BOOTSEL 或配置页"引导模式"，分别刷写两块板。
- 详见第 10.4 节。

### 12.9 提交问题

如果以上方法无法解决，请在 [GitHub Issues](https://github.com/likeaturtle/Movio/issues) 提交问题，并尽量包含：

- Movio 固件版本和校验值（配置页"设备状态"）；
- 硬件版本（PCB v1.0/v1.1、Pico 接口类型）；
- 两台电脑的操作系统和版本；
- 键盘、鼠标的品牌和型号（有线/无线/接收器类型）；
- 连接方式（直连/集线器/扩展坞）；
- 复现步骤、现象和已尝试的处理；
- 配置页截图（注意遮盖敏感信息）；
- 板载 LED/键盘 LED 的闪烁行为；
- 如果是 DIY 主板，附上焊接相关照片。

> 如果问题涉及安全漏洞，请不要在公开 Issue 中披露细节，先通过项目仓库提供的私密渠道联系维护者。

## 13. 安全与隐私

### 13.1 数据安全

- **不传输数据**：Movio 不支持复制粘贴、文件传输、剪贴板共享或任何跨电脑的数据通道。
- **不保留输入历史**：设备不记录按键内容、鼠标轨迹或输入历史。
- **只转发标准 HID**：键盘、鼠标报告只发送给当前活动输出；非活动输出不会收到键鼠输入。
- **无网络**：没有 Wi-Fi、蓝牙、以太网或互联网连接，也没有遥测。
- **本地配置**：配置页完全在本地运行，不加载外部 JavaScript，也不上传配置数据。

### 13.2 硬件隔离

- 两路输出之间通过数字隔离器实现 **2kV 设计隔离电压**。
- PCB v1.1 增加 ESD/TVS 保护，提升 USB 端口的静电防护能力。
- 无无线通信模块，减少无线攻击面。
- 隔离用于信号侧电气隔离，不构成市电安全隔离等级；不要用于高压、医疗或安全关键场景。

### 13.3 访问控制

- 配置模式需要用户通过快捷键主动进入；配置页通过 WebHID 连接时需要用户明确授权。
- 正常模式下不暴露厂商自定义 HID 接口；只有配置模式才启用。
- 板间通信使用固定长度数据包，配置项有白名单，大部分状态为只读。
- 配置模式约 5 分钟无操作自动退出，降低遗忘风险。
- 来自电脑的键盘 LED 报告只允许单字节输出报告，不提供任意写入通道。

### 13.4 设备保护

- 不信任任何连接的电脑；设备不会因为某台电脑的请求而主动生成按键。
- 固件升级只能由用户在配置模式或物理 BOOTSEL 下触发；不支持由输出电脑远程触发。
- 屏幕锁定快捷键由用户主动按下 `右 Ctrl` + `L` 触发；屏幕保护会产生鼠标移动，但不会产生点击或按键。
- 跨设备固件同步可以在编译时通过 `DISABLE_FW_UPGRADE` 关闭，适合高安全场景。
- 不向外接键盘/鼠标暴露自定义端点，也不向它们转发数据。

### 13.5 透明度与局限

- 项目代码以 GPLv3 开源，硬件设计开放，便于审计。
- 固件完整性使用 CRC32 校验，**不是密码学签名**；请从可信来源下载固件。
- Movio 不能防御已被攻陷的电脑、恶意外设固件、物理接触攻击或供应链篡改。
- Movio 不能替代物理隔离网闸、数据二极管或组织规定的安全边界。
- 如果两台电脑属于不同安全域，请先咨询安全负责人，不要仅凭本设备做隔离决策。

## 14. 维护与保养

### 14.1 日常维护

- 用干燥、柔软的无绒布清洁外壳；不要使用酒精、溶剂或研磨性清洁剂。
- 避免液体、灰尘、金属碎屑进入 USB 口和外壳开孔。
- 插拔 USB 线时握住插头，不要直接拉拽线缆。
- 避免设备长期受到阳光直射、高温、潮湿或强烈振动。
- 设备工作时轻微发热是正常的；如果明显过热，请断开电源并检查。
- 不需要定期加注润滑油或更换电池；设备没有可更换电池。

### 14.2 外壳拆装

- 3D 打印外壳为卡扣式设计，通常无需螺丝。
- 需要开壳时，先断开所有 USB 线。
- 可用小号一字螺丝刀从外壳底部的槽口轻轻撬开；避免用力过猛损坏卡扣。
- 安装时先对准定位柱，再按压卡扣；不要压到内部线缆或电路板。
- 反复拆装会磨损卡扣；如果卡扣断裂，可重新打印外壳或使用少量胶带固定。

### 14.3 存放与运输

- 长期不使用时，断开所有线缆，放入防静电袋或干燥盒中。
- 避免与尖锐物品、潮湿物品一起存放。
- 运输时使用缓冲材料保护 USB 接口和外壳，避免重压。
- 存放环境应干燥、阴凉、无凝露。

### 14.4 固件与配置管理

- 定期查看 [Releases](https://github.com/likeaturtle/Movio/releases)，获取稳定性和兼容性更新。
- 升级前记录配置页截图和当前版本。
- 保留一份已知可用的 `movio.uf2`，以便需要时恢复。
- 如果设备长期稳定运行，不必频繁升级；升级前先阅读发布说明。
- 恢复默认配置不会影响固件；恢复固件不会自动恢复配置，二者需要分别处理。

## 16. 常见问题

### Q1. Movio 是视频 KVM 吗？

不是。Movio 只切换键盘和鼠标，显示器、音箱、摄像头等仍直接连接各自的电脑。因为视频不经过 Movio，所以不会影响分辨率、刷新率、HDR 或色彩。

### Q2. 需要安装驱动或软件吗？

不需要。两台电脑都把它识别为标准 USB HID 键鼠设备。配置页是本地 HTML 文件，只在需要修改参数时使用，不是常驻软件。

### Q3. 两台电脑都必须开机吗？

是的。每块板由对应电脑的 USB 口供电；只开一台电脑时，另一块板没有供电，双机切换无法正常工作。大多数台式机和笔记本在关机状态下仍提供 USB 供电，但仍建议两台都开机。

### Q4. 支持无线键鼠吗？

支持带 USB 接收器的 2.4GHz 无线键鼠，包括罗技 Unifying 等组合接收器。纯蓝牙键鼠没有 USB 接收器，Movio 没有蓝牙功能，因此不支持。

### Q5. 支持罗技 Unifying 等组合接收器吗？

支持。近期固件对组合接收器做了兼容性改进。如果识别异常，可以尝试重新插拔、换 USB 口、使用延长线，或开启"强制键盘启动协议/强制鼠标启动模式"。

### Q6. 能在两台电脑之间拖拽文件或复制粘贴吗？

不能。这是有意的安全设计：Movio 不提供任何跨电脑数据通道，不支持剪贴板、文件传输或拖拽。

### Q7. 为什么鼠标到屏幕边缘不切换？

常见原因：屏幕位置配置错误、跳转阈值过大、开启了游戏模式或切换锁定、按住鼠标按键、当前不在主屏、多屏布局与配置不一致。请按第 12.4 节排查。

### Q8. 为什么切换后光标高度不一样？

两台显示器尺寸、分辨率或垂直位置不同。请按第 5.6 节或第 9.1 节校准上/下边界。

### Q9. 为什么 Caps Lock 灯一直亮/不亮？

可能开启了"键盘 LED 作为状态灯"。此时 Caps Lock 灯表示当前输出：亮 = 输出 B，灭 = 输出 A，不再表示大写锁定。如果希望恢复原本的 Caps Lock 指示，请在配置页关闭该选项。

### Q10. Firefox 或 Safari 能打开配置页吗？

不能。配置页使用 WebHID，Firefox 和 Safari 不支持。请使用 Chrome、Chromium 或 Edge。

### Q11. 为什么配置页看起来是压缩过的代码？

`config.htm` 为节省设备存储空间做了压缩和自解压处理，用浏览器打开时会自动展开。完整源码在项目的 `webconfig/` 目录中，可自行审计和重新生成。

### Q12. 为什么不做成在线配置页？

从外部加载 JavaScript 来操作输入设备存在安全风险。Movio 的配置页完全本地运行，不加载外部资源，也不上传数据。

### Q13. 可以只接一台电脑使用吗？

不建议。Movio 的两块板分别由两台电脑供电，设计为双机使用；只接一台电脑时另一块板没有供电，双机切换无法正常工作。如果只需要一台电脑，使用普通 USB 集线器连接键鼠更简单。

### Q14. 每台电脑最多支持几块屏幕？

Web 配置页每路提供 1–3 块屏幕，两台电脑合计最多 6 块。Linux 通常应设为 1，由桌面环境管理多显示器。若需要更多屏幕，请确认固件和页面版本；当前版本以页面选项为准。

### Q15. 固件升级会丢失配置吗？

通常不会，但配置结构版本变化时设备会自动恢复默认配置。升级前建议截图记录配置；升级后检查操作系统、屏幕位置、屏幕数量和边界值。

### Q16. 支持降级吗？

自动同步只会在对方版本更新时触发，不会自动降级。如需降级，请分别用 BOOTSEL 刷写两块板到同一旧版本。

### Q17. 能用于 BIOS/UEFI 或 BitLocker 吗？

可以尝试。部分主板需要开启"强制键盘启动协议"；在 BIOS 中操作另一台电脑前，先用 `左 Ctrl` + `Caps Lock` 切换输出。若仍无响应，请尝试直连 USB 口、换键盘或更新固件。

### Q18. 会影响游戏、高刷新率或 HDR 吗？

不会。视频信号不经过 Movio。游戏方面，如果遇到绝对坐标不兼容，请开启游戏模式使用相对鼠标。

### Q19. 设备发热正常吗？

轻微发热正常。如果明显过热、有异味或外壳变形，请立即断开所有 USB 并停止使用。

### Q20. 如何恢复出厂设置？

按 `右 Shift` + `F12` + `D`，或在配置页点击"清除配置"。这会恢复默认配置，但不会删除固件。恢复后需要重新设置操作系统和屏幕位置。

```text
进入/退出配置模式：左 Ctrl + 右 Shift + C + O
```


### 17.3 配置建议速查

| 目标 | 建议 |
|------|------|
| 双机各一屏 | 屏幕数 1；位置按实际左/右；OS 按实际 |
| 防止误切换 | 跳转阈值 200–500 |
| 切换困难 | 跳转阈值 0 |
| 精确定位 | `右 Ctrl` + `右 Alt` 慢速鼠标，或降低速度 X/Y |
| 鼠标发飘 | 关闭"启用加速"；降低速度 |
| 游戏/虚拟机 | 开启游戏模式，或"游戏模式默认开启" |
| 多屏 | 主屏紧邻另一台电脑，扩展屏向外；先设 1 屏验证 |
| Linux 多屏 | 屏幕数量设为 1 |
| 防止锁屏 | 屏幕保护设为弹球/抖动，勾选"仅不活跃时" |
| 需要 Caps Lock 指示 | 关闭"键盘 LED 作为状态灯" |
| 键盘在 BIOS 无响应 | 开启"强制键盘启动协议" |
| 鼠标兼容性差 | 开启"强制鼠标启动模式" |
| 键盘/鼠标接反 | 关闭"强制端口"，或按实际位置接线 |
