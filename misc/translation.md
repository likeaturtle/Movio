# 第3章 - 配置

## 设置切换高度偏移量

物理尺寸和（或）分辨率不相同的屏幕间会存在高度差，为了使鼠标指针在不同屏幕上以相同的高度出现以改善用户体验，有必要告诉系统您的屏幕高度差异是多少。

## 要执行此操作：

1. 将鼠标光标留在较大的屏幕上，并将鼠标光标置于较小/较低屏幕的高度（如图所示），然后按 右 Shift + F12 + Y，此时 Movio 和键盘大写锁定键的 LED 灯应闪烁以确认操作已执行。

![alt text](<../img/图片 2.png>)

2. 在底部边框重复上述操作（如果需要）。

3. 操作完成后，相关数据将保存到 Movio，后续使用过程中将以本次设置的高度偏移量为标准。

## 多显示器解决方案

Windows 和 Mac 操作系统在多屏幕和绝对定位方面存在问题，因此必须为每个输出设置操作系统和屏幕数量。

您的主屏幕需要在置于中间位置，次要屏幕置于侧方位并依次排开。要配置实际选项，请打开设备的网页配置页面。

## 进入配置模式

1. 按下 左 Ctrl + 右 Shift + C + O 后， Movio 将自动重启并进入配置模式。Movio 内的 LED 灯和大写锁定键 LED 灯将在配置会话期间持续闪烁。

2. 打开A口所连接电脑内出现的 USB 存储驱动器（名为MOVIO），其中包含一个文件 config.htm

3. 用 Chromium / Chrome 打开该文件（Firefox 因不支持 WebHID 而无法使用）。

4. 单击连接并允许 Movio 设备配对。

![alt text](<../img/图片 3.png>) 
图2：如果一切顺利，您应该看到此配置页面

在配置页面上的任何更改都会即时下发至设备。全部修改完成后请点击保存按钮，并点击退出按钮退出修改。

解释选项：

• 屏幕数量：当前主机配置显示器数量。

• 屏幕数量-速度 X 和屏幕数量-速度 Y ：当前主机鼠标在X和Y轴上的移动速度。

• 上边界和下边界：用于设置高度偏移量，取值范围为0（顶部）到 32767（底部）。为简单起见，建议使用右 Shift + F12 + Y快捷键进行交互式调整。

• 光标停靠位置：定义使用快捷键切换光标所在屏幕时，光标被移动到当前未活动的计算机上的位置

• 屏幕保护-模式：防止计算机进入睡眠状态，您可以选择 pong（光标四处弹跳）、jitter（光标移动 1 像素）或 none（关闭）。

• 屏幕保护-空闲时间：用于设置在无操作多久后开启屏幕保护，以微秒为单位。

• 屏幕保护-最大时间：用于设置屏幕保护允许运行的最大时长。以微秒为单位。

• 鼠标-强制鼠标启动模式：以简单模式初始化鼠标，可临时解决使用过程中遇到的部分鼠标问题。

• 键盘-强制端口：可临时解决使用过程中遇到的部分键盘问题。

• 键盘 LED 作为状态灯：允许使用大写锁定键进行LED灯光信号发送。

请注意，闪烁的大写锁定键 LED 灯（如有）是为了提醒您设备处于配置模式。如果一段时间内没有配置活动。出于安全考虑，您的设备将重启回到正常模式，相应的USB驱动器也将消失。

## 第4章 - 固件升级

## 现有固件升级（常用）

如果Movio正常运转并希望升级到更新的版本，则需要：

1. 从 https://github.com/hrvach/Movio/releases 下载 Movio.uf2 文件

2. 按 左 CTRL + 右 SHIFT + "c" + "o" 进入配置模式

3. 打开A口所连接电脑内出现的 USB 存储驱动器（名为MOVIO），将 Movio.uf2 复制到其中，并保持线缆连接。

4. Movio的两个绿色LED灯将持续闪烁，灯光闪烁停止即代表升级完成，此时可正常使用。


## 初始固件部署（应急）

此过程可在任何时间点出现任何问题时对Movio固件进行恢复。

1. 访问 https://github.com/hrvach/Movio/releases 并选择最新的稳定版本

2. 下载 Movio.uf2 文件

3. 将 Type-C线缆连接电脑，并将另一端插入A口

4. 打开A口所连接电脑内出现的 USB 存储驱动器（名为MOVIO），将 Movio.uf2 复制到其中

5. 对B口重复上述操作。


## 第6章 - 安全与防护

## 数据安全

• 不支持复制粘贴文字、文件或任何信息共享以防止信息泄露。

• 不支持保留任何输入历史记录。

• 禁止设备主动生成任何按键输入，任何情况下输出内容仅允许为用户手动输入或主动触发产生的内容

## 硬件安全

• 输出在物理上分离并电隔离，最小隔离电压为 2kV。

• 通过完善的TVS设计，实现ESD/浪涌保护，有效避免静电和瞬间非正常供电变化导致的硬件损坏。

• 支持自动化的双电源自动切换，无需人为手动切换供电输入口（先插入的Type-C接口负责供电），供电失效时自动切换至另一Type-C接口供电，确保供电稳定同时

• 无蓝牙、 wifi、网络、互联网访问等。

## 访问控制

• 未经用户明确许可，不可执行任何 WebHID 设备管理操作。禁止输出端计算机建立入站连接，唯一例外为标准键盘灯光开关指令，且数据严格限制为单字节。

• 设备间交互的所有数据包均为固定长度；可传输的配置项仅有少量固定清单，绝大多数配置项为只读状态。

## 设备保护

• 任何情况下，接入的计算机均不视作可信设备。

• 配置模式下，无操作超时将自动退出。

• 不会对外暴露外接键盘、鼠标的自定义端点，也不会向这类设备转发数据；可通过隔离防护机制，将设备潜在漏洞与主机完全隔绝。

• 禁止由输出端设备发起固件升级操作；仅能由用户通过专属快捷键主动、手动触发升级。
