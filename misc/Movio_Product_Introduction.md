# Movio 产品与功能介绍

**Movio** 是一款开源硬件 KVM 切换器，基于 [hrvach/deskhop](https://github.com/hrvach/deskhop) 项目深度优化而来。它允许用户通过一套键盘和鼠标无缝操控两台计算机——只需将鼠标指针拖拽到屏幕边缘，即可在不同电脑间自由切换，键鼠自动跟随，操作体验如同使用同一台机器。

## 1. 产品概述

### 1.1 它解决什么问题？

在日常工作中，许多人需要同时使用两台电脑（例如一台 Windows 工作机 + 一台 macOS 个人机）。传统的 USB 切换盒需要手动按按钮切换，操作繁琐且存在延迟。软件方案（如 Barrier、Synergy）则需要在两台电脑上安装软件，存在兼容性和安全顾虑。

Movio 通过纯硬件方案解决了这个问题：**零延迟切换、无需安装软件、跨操作系统兼容、完全物理隔离**。

### 1.2 设计理念

- **安全性优先**: 输出端物理隔离（2kV 隔离电压），无网络/蓝牙，无数据跨设备传输
- **极简硬件**: 仅需两块 Raspberry Pi Pico + 一块数字隔离器，总成本低于 15 欧元
- **开源开放**: 完全开源，无二进制固件，鼓励用户自行审计和编译

## 3. 工作原理

Movio 作为键盘/鼠标与两台计算机之间的中介设备，同时与两台电脑维持 USB 连接。它根据用户的选择，将键鼠输入转发到对应的电脑。

### 3.1 鼠标切换

设备将鼠标 HID 报告改为绝对坐标模式，内部累加相对移动值以维护精确位置。当鼠标移向另一台电脑方向并越过屏幕边界时，保持 Y 坐标不变，交换 X 轴极值，同时切换输出目标。鼠标指针将在另一台电脑的屏幕上以相同高度无缝出现。

![鼠标穿屏演示](../img/deskhop-demo.gif)

<p align="center">从 Mac 拖拽鼠标到 Linux，自动切换输出</p>

### 3.2 键盘跟随

键盘随鼠标自动切换——当鼠标切换到另一台电脑时，键盘输入也会自动转发到同一台电脑。反之亦然。此外，也可以通过快捷键（默认 `左 Ctrl + 大写锁定键`）独立切换。

### 3.3 LED 状态指示

Movio 会记住每台电脑的键盘 LED 状态（如大写锁定灯），切换时自动恢复对应状态。用户也可以将键盘 LED 复用为输出指示灯，直观显示当前活跃的电脑。

## 4. 硬件设计

### 4.1 核心组件

| 组件 | 型号 | 作用 |
|------|------|------|
| 主控 x2 | Raspberry Pi Pico (RP2040) | 双核 MCU，一块负责 A 输出，一块负责 B 输出 |
| 数字隔离器 | TI ISO7721DR（推荐）或 ADuM1201BRZ | 实现两输出端的物理电气隔离 |
| ESD 保护 x2 | TPD4E1U06DBVR（PCB v1.1） | USB 端口静电防护 |
| USB-A 连接器 x2 | Molex MX-67643-0910 或兼容型号 | 键盘/鼠标输入端口 |
| 限流电阻 x4 | 0805 SMD 27Ω（PCB v1.1） | USB 信号阻抗匹配 |

### 4.2 PCB 设计

![PCB 实物图](../img/plocica2.png)

- **层数**: 单面走线，便于 DIY 焊接
- **阻抗**: USB 差分阻抗设计目标 90Ω
- **厚度**: 1.6mm（卡扣外壳配合所需）
- **两个版本**:
  - v1.0: 更易焊接，适合初学者
  - v1.1: 增加 ESD 保护、VBUS 电容、丝印方向标记、27Ω USB 限流电阻

## 5. 安装与连接

### 5.1 连接示意图

```
  键盘 ──→ [键盘图标 USB 口] ─┐
                               │    Movio 设备
  鼠标 ──→ [鼠标图标 USB 口] ─┤
                               ├─→ Type-C ──→ 电脑 A
                               └─→ Type-C ──→ 电脑 B
```

### 5.2 连接步骤

1. **连接鼠标**: 将鼠标插入带有鼠标图标的 USB 输入端口
2. **连接键盘**: 将键盘插入带有键盘图标的 USB 输入端口
3. **连接电脑**: 使用 Type-C 线缆分别连接两台电脑的 USB 端口
4. **确认连接**: 设备 LED 会闪烁，表示键盘/鼠标已被成功检测到
5. **开机使用**: 打开两台电脑，即可开始使用键鼠穿屏功能

> **注意**: 请确保两台电脑和 Type-C 线缆均能正常传输数据和供电。两台电脑都需要连接并提供 USB 供电，设备才能正常工作。多数现代台式机和笔记本电脑在关机状态下也会通过 USB 端口供电。

### 5.3 初次固件部署

如果设备是全新组装（空白固件），需要先刷入固件：

1. 从 [GitHub Releases](https://github.com/likeaturtle/Movio/releases) 下载 `movio.uf2` 文件
2. 将 Type-C 线缆连接电脑，另一端插入 A 口
3. 电脑将出现名为 "MOVIO" 的 USB 存储驱动器
4. 将 `movio.uf2` 复制到该驱动器
5. 对 B 口重复上述操作

### 5.4 LED 状态指示

| LED 行为 | 含义 |
|----------|------|
| 插入外设时闪烁两次 | 新 USB 设备已被检测到 |
| 持续闪烁 | 设备处于配置模式 |
| 交替快速闪烁 | 正在执行固件升级 |
| 常亮/灭 | 表示当前活跃的输出端 |

## 6. 键盘快捷键

### 6.1 配置快捷键

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 进入配置模式 | `左 Ctrl` + `右 Shift` + `C` + `O` | 设备重启并挂载 USB 配置驱动器 |
| 重置 Flash 配置 | `右 Shift` + `F12` + `D` | 清除所有已保存的配置 |
| 保存屏幕高度偏移 | `右 Shift` + `F12` + `Y` | 将当前鼠标高度差保存为切换偏移量 |

### 6.2 使用快捷键

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 切换键鼠所在屏幕 | `左 Ctrl` + `大写锁定键` | 在两台电脑间切换活跃输出 |
| 游戏模式 | `左 Ctrl` + `右 Shift` + `G` | 锁定当前屏幕，鼠标切换为标准相对模式 |
| 启用屏幕保护 | `左 Ctrl` + `右 Shift` + `S` | 防止电脑进入休眠 |
| 禁用屏幕保护 | `左 Ctrl` + `右 Shift` + `X` | 关闭屏幕保护 |
| 慢速鼠标模式 | `右 Ctrl` + `右 Alt` | 减慢鼠标移动速度，便于精确操作 |
| 锁定/解锁到当前屏幕 | `右 Ctrl` + `K` | 防止意外切换到另一台电脑 |
| 同时锁定两台电脑 | `右 Ctrl` + `L` | 需预先在配置中设置各输出端的操作系统 |

## 7. Web 配置界面

Movio 提供了一个基于 WebHID 的本地网页配置界面，用于调整设备参数。

### 7.1 进入配置模式

1. 按下 `左 Ctrl` + `右 Shift` + `C` + `O`，设备将自动重启进入配置模式
2. LED 灯将在配置期间持续闪烁
3. 电脑上将出现名为 **"MOVIO"** 的 USB 存储驱动器
4. 打开其中的 `config.htm` 文件（需使用 Chrome 或 Chromium 浏览器，Firefox 不支持 WebHID）
5. 点击 **"连接"** 按钮并允许设备配对

![配置页面](../img/connect-dialog.png)

![完整配置界面](../img/config-page-big.png)

### 7.2 语言切换

页面右上角提供 `EN / 中文` 切换按钮，支持中英文双语界面。语言偏好会自动保存到浏览器本地存储。

### 7.3 配置选项说明

#### 输出 A / 输出 B 配置（每台电脑独立配置）

| 选项 | 说明 |
|------|------|
| 屏幕数量 | 当前主机配置的显示器数量（1-3） |
| 速度 X / 速度 Y | 鼠标在 X/Y 轴上的移动速度（1-100） |
| 上边界 / 下边界 | 设置屏幕高度偏移量（0-32767），用于对齐不同尺寸的屏幕 |
| 操作系统 | 选择当前输出端的操作系统（Linux/macOS/Windows/Android/其他） |
| 屏幕位置 | 该输出端在整体布局中的位置（左/右） |
| 光标停靠位置 | 使用快捷键切换时，光标在非活跃电脑上的位置（上/下/上次位置） |

#### 屏幕保护配置

| 选项 | 说明 |
|------|------|
| 模式 | 禁用 / Pong（光标弹跳）/ Jitter（光标抖动 1px） |
| 仅不活跃时 | 仅在用户不活跃时启用屏幕保护 |
| 空闲时间 | 无操作多久后启用屏幕保护（微秒） |
| 最大时间 | 屏幕保护允许运行的最长时间（微秒） |

#### 通用配置

| 选项 | 说明 |
|------|------|
| 强制鼠标启动模式 | 以简单模式初始化鼠标，可解决部分鼠标兼容问题 |
| 强制键盘启动协议 | 以启动协议模式初始化键盘，可解决部分键盘兼容问题 |
| 键盘 LED 作为状态灯 | 允许使用键盘大写锁定灯作为输出状态指示 |
| 强制端口 | 强制使用特定 USB 端口，可解决部分设备兼容问题 |
| 跳转阈值 | 鼠标跨越屏幕边界所需的额外移动距离（0-3000） |

#### 设备状态（只读）

| 选项 | 说明 |
|------|------|
| 当前固件版本 | 显示正在运行的固件版本号 |
| 当前固件校验值 | 显示固件 CRC32 校验值 |

### 7.4 操作按钮

| 按钮 | 功能 |
|------|------|
| **连接** | 通过 WebHID 连接到 Movio 设备 |
| **读取** | 从设备读取当前所有配置值 |
| **保存** | 将当前配置写入设备 Flash 存储 |
| **退出** | 退出配置模式，设备重启回到正常模式 |
| **闪烁** | 使当前输出端 LED 闪烁（用于识别设备） |
| **双闪** | 使两个输出端 LED 同时闪烁 |
| **引导模式** | 将设备切换到 bootloader 模式（用于固件刷写） |
| **清除配置** | 擦除所有已保存配置并恢复默认值 |

> **注意**: 配置页面的所有修改会即时下发至设备，但只有点击 **"保存"** 后才会持久化到 Flash。如果一段时间内无配置操作，设备将自动退出配置模式以确保安全。

### 7.5 Linux 用户注意

在 Linux 上使用 Chromium 连接设备时，可能需要创建 udev 规则：

```bash
# /etc/udev/rules.d/99-movio.rules
KERNEL=="hidraw*", SUBSYSTEM=="hidraw", ATTRS{idVendor}=="1209", ATTRS{idProduct}=="c000", GROUP="plugdev", MODE="0660"
```

确保当前用户在 `plugdev` 组中，并重新加载 udev 规则。

## 8. 固件升级

### 8.1 在线升级（推荐）

当设备正常运行且需要升级到新版本时：

1. 从 [GitHub Releases](https://github.com/likeaturtle/Movio/releases) 下载最新的 `movio.uf2` 文件
2. 按 `左 Ctrl` + `右 Shift` + `C` + `O` 进入配置模式
3. 打开电脑上出现的 "MOVIO" USB 驱动器
4. 将 `movio.uf2` 复制到驱动器中，保持线缆连接
5. 两个绿色 LED 灯将持续闪烁，闪烁停止即表示升级完成
6. 设备将自动重启，随后升级另一块板子的固件

> **注意**: "MOVIO" 驱动器不是真正的 USB 存储设备，仅用于接收固件文件。

### 8.2 应急恢复

当设备出现任何异常需要恢复时：

1. 下载最新版本的 `movio.uf2` 文件
2. 将 Type-C 线缆连接电脑，另一端插入 A 口
3. 打开出现的 "MOVIO" USB 驱动器，复制 `movio.uf2`
4. 对 B 口重复操作

### 8.3 ROM Bootloader 方式

按住 Pico 板载按钮的同时插入 USB 线缆，电脑将出现 "RPI-RP2" 驱动器，将 `.uf2` 文件复制到其中即可。

## 9. 进阶功能

### 9.1 屏幕高度校准

当两台电脑的屏幕物理尺寸或分辨率不同时，鼠标切换时可能出现高度不一致。校准步骤：

1. 将鼠标放在**较大的屏幕**上，移动到与较小屏幕对应高度的位置
2. 按下 `右 Shift` + `F12` + `Y`
3. LED 和大写锁定灯将闪烁确认
4. 如需要，在底部边界重复操作
5. 偏移量将保存到设备 Flash，后续使用自动生效

### 9.2 多显示器配置

Windows 和 macOS 在多屏幕绝对定位方面存在兼容性问题，需要额外配置：

1. 进入 Web 配置页面
2. 为每个输出端设置正确的**操作系统**和**屏幕数量**
3. 主屏应置于中间位置，副屏依次排开在两侧

### 9.3 游戏模式

部分游戏不兼容绝对坐标鼠标模式。按 `左 Ctrl` + `右 Shift` + `G` 切换游戏模式：

- 锁定在当前屏幕，不响应穿屏操作
- 鼠标切换为标准相对模式
- 适用于游戏、虚拟机等特殊场景
- 再次按同一快捷键退出游戏模式

### 9.4 慢速鼠标模式

按 `右 Ctrl` + `右 Alt` 切换慢速鼠标模式：

- 鼠标移动速度大幅降低
- 适用于精确定位（如拖动视频进度条、精确绘图等）
- 再次按同一快捷键恢复正常速度

### 9.5 屏幕保护

默认关闭。可选择 Pong（光标弹球）或 Jitter（1px 抖动）模式，防止电脑进入休眠。适用于有 USB 扩展坞休眠后无法唤醒等问题的场景。

## 10. 安全与防护

### 10.1 数据安全

- **无跨设备数据传输**: 不支持复制粘贴、文件传输或任何信息共享，从根本上防止信息泄露
- **无输入历史**: 设备不保留任何输入记录
- **被动式转发**: 设备禁止主动生成任何按键输入，所有输出仅限于用户手动输入或主动触发

### 10.2 硬件安全

- **物理隔离**: 输出端通过数字隔离器实现 2kV 最小隔离电压
- **ESD/浪涌保护**: 完善的 TVS 设计有效防护静电和瞬态电压
- **自动供电切换**: 双 Type-C 接口自动切换供电，无需手动操作；先插入的接口负责供电，失效时自动切换到另一个
- **无无线通信**: 无蓝牙、WiFi、网络或互联网访问

### 10.3 访问控制

- WebHID 设备管理操作需用户明确许可
- 禁止输出端计算机建立入站连接（唯一的例外是标准键盘灯光开关指令，严格限制为单字节）
- 设备间交互的所有数据包均为固定长度，可传输的配置项仅有少量固定清单，绝大多数为只读状态

### 10.4 设备保护

- 接入的计算机在任何情况下均不被视为可信设备
- 配置模式下无操作超时将自动退出
- 不对外暴露外接键盘/鼠标的自定义端点，不会向这些设备转发数据
- 禁止由输出端设备发起固件升级操作，仅能由用户通过专属快捷键手动触发

Movio 基于 DeskHop 项目进行了一系列深度优化，涵盖品牌重塑、界面升级、固件修复和功能增强。

### 11.1 品牌与视觉

- 全新橙色主题色（`#ff6600`），替代原版绿色
- 重新设计的 SVG 图标和页面 favicon

### 11.2 Web 配置界面

- **中英文国际化**: 完整的双语支持，页面右上角一键切换，默认中文
- **交互反馈**: 按钮点击后显示 "✓ 已执行"，保存成功后显示绿色 "完成"
- **自定义滑块**: 跨浏览器一致的 range input 样式，解决 Chromium Linux 渲染问题
- **Bootloader 修复**: 修复原版中 bootloader 按钮无法正常工作的问题

### 11.3 固件稳定性

- **边界检查修复**: 4 处 off-by-one 越界问题（数组索引、接口编号等）
- **CRC32 类型修复**: 校验值从 `uint8_t` 修正为 `uint32_t`，原版截断了 32 位校验值
- **HID 解析增强**: NKRO 提取失败时自动回退到标准提取器，兼容更多键盘
- **系统报告长度检查**: 防止越界读取系统控制报告

### 11.4 鼠标行为优化

- **虚拟桌面平滑切换**: 区分本地切换（虚拟桌面，阈值=0）和跨设备切换（保留阈值），本地操作更流畅

### 11.5 LED 管理

- 新增 `desired` / `actual` 双状态分离，LED 指示更准确
- 新增 `led_sync_task()` 同步任务，30Hz 周期检查并自动修正状态差异

### 11.6 构建系统

- 新增 `build_all.sh` 一键构建脚本（网页打包 + 磁盘镜像 + 固件编译）
- CMake 版本号支持外部传入
- 完善 `.gitignore` 规则

## 12. 常见问题

### Q: 两台电脑的显示器分辨率不同会有问题吗？
不会。鼠标移动在抽象坐标空间中进行，由各电脑自行映射到物理屏幕。

### Q: 键盘/鼠标切换时，另一个会自动跟随吗？
是的。当鼠标切换到另一台电脑时，键盘输入也会自动转发到同一台电脑，反之亦然。

### Q: 支持罗技 Unifying 等键鼠合一接收器吗？
支持。固件更新后对多合一接收器的兼容性已大幅改善。

### Q: 支持独立无线接收器的无线键鼠吗？
支持。经过测试，带有独立无线接收器的无线鼠标和键盘均可正常工作。

### Q: Firefox 浏览器能打开配置页面吗？
不能。配置页面使用 WebHID API，Firefox 目前不支持此特性，请使用 Chrome 或 Chromium。

### Q: 为什么配置页面看起来是压缩的？
这是有意为之。由于设备存储空间有限，配置页面采用自解压格式。完整的源代码在项目仓库中公开，鼓励自行编译。

### Q: 为什么配置页面不做成在线版？
从外部加载 JavaScript 来操作输入设备存在安全风险。Movio 的配置页面完全本地运行，不加载任何外部资源。

### Q: 两台电脑都需要通电吗？
是的。每块板子由所连接的电脑通过 USB-C 供电。多数现代电脑在关机状态下也会通过 USB 端口供电。如果需要仅使用一台电脑，可以通过 USB 集线器将键盘和鼠标连接到同一个 USB-A 端口，否则仅通电侧 USB-A 口插入设备可用。
