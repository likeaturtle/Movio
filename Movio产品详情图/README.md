## 文件说明

| 路径 | 内容 |
| --- | --- |
| `out/upload_1500/` | **上传用**：1500px 宽、17 张 JPG（全部 > 1440px），可直接拖进淘宝详情编辑器 |
| `out/` | 高清母版：1500px 宽（2 倍图），与上传包同一份文件 |
| `out/预览/` | 查看用：`index.html` 逐屏浏览 + `全页长图.jpg`（1500 × 39106，仅供查看，不上传） |

| `assets/` | 从文档中提取的产品图与配置页截图 |

## 设计规范

- 画布 750px 宽（导出 2 倍 → 1500px 成品），每屏高 860–1490px（成品 1720–2980px），单屏高度均不超过 3000px。
- 主色 `#FF6A00`（取自 Movio 火焰标识），全页统一暖白底 `#FAF7F2`；卡片用纯白 `#FFFFFF`，提示块用米色 `#F6EDE2` / `#EFE8DD`，不再使用深色底。
- 中文 PingFang SC，数字与英文 Avenir Next；正文 19–24px，标题 47px，封面主标 84px。
- 17 屏统一浅色底，靠白色卡片、米色提示块与橙色编号形成层次，整页滚动无色块跳变。

## 上传建议

1. 打开淘宝卖家中心 → 商品 → 详情描述，将 `out/upload_1500/` 中的 JPG 按 00 → 16 的顺序依次插入。
2. 单张最大 765 KB，均在淘宝 3 MB 限制内；若编辑器要求宽度 ≤ 750px，可让我再导出一套 750px。
3. 首屏 `01_封面.jpg` 也可裁成 `800×800` 作为主图第 2 张（主图第 1 张建议用纯产品实拍）。
4. 详情页中已注明「外观与主板为示意图，实物以最终版本为准」「本页文案整理自…V1.0」，如产品版本更新请同步修改。

## 修改方式

```bash
# 修改文案：编辑 src/screens.py
# 修改配色/字号：编辑 src/theme.css
python3 src/build.py            # 重新生成全部（含整页预览）
python3 src/build.py 01 09      # 只重新生成指定屏
```

渲染依赖本机 Chrome（headless）与 Python 的 Pillow；生成 1500px 母版后，再按需导出 750px 版本；如需新增屏幕，注意单屏高度不要超过 1500 CSS px（成品 3000px）。
