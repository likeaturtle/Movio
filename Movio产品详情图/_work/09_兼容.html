MOVIO
SEAMLESS KVM · 双机键鼠切换器
08 — 兼容

标准 USB HID，
插上就是键鼠。

电脑把 Movio 识别为标准 HID 键鼠设备：不装驱动，也不会多出磁盘、网卡或未知设备。

Windows 10 / 11
支持
多屏使用兼容模式
macOS
支持
多屏为实验性；锁定快捷键 Ctrl + Cmd + Q
Linux
支持
多屏建议屏幕数量设为 1，由桌面环境管理
Android
支持
需要 OTG；建议单屏，必要时用游戏模式
BIOS / UEFI
BitLocker
视主板
部分主板需开启“强制键盘启动协议”

未列出的系统（iOS / iPadOS、ChromeOS 等）未经验证，不建议依赖。视频不经过 Movio，因此不影响分辨率、刷新率、HDR 与色彩。
