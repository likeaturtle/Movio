SEAMLESS KVM · 双机键鼠切换器
09 — 快捷键

十一个组合键，
记住三个就够用。

全部由键盘直接触发，不装驱动；除“慢速鼠标”外，组合都会被 Movio 拦截，不会输入到电脑。

配置类 · 进入设置与校准
进入 / 退出配置模式
左 Ctrl+右 Shift+C+O
重置配置（无二次确认）
右 Shift+F12+D
保存屏幕高度
右 Shift+F12+Y
使用类 · 日常操作
切换输出
左 Ctrl+Caps Lock
游戏模式
左 Ctrl+右 Shift+G
慢速鼠标
右 Ctrl+右 Alt
切换锁定
右 Ctrl+K
锁定两台电脑
右 Ctrl+L
屏幕保护另有三个组合：左 Ctrl + 右 Shift + S / J / X（弹球 / 抖动 / 关闭），只对当前活动输出生效，不写入 Flash。

快捷键目前不能在 Web 配置页中修改；如需更改，需要在源码 user_config.h 中重新定义并编译固件。
